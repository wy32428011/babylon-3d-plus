# AGV 地图 DXF 导入与修正规范

本规范适用于 3D 编辑器 **AGV 产生器「地图上传（DXF）」** 功能。后续接入新的 CAD 图纸或改造第三方 DXF 时，请按本规范检查与修正，确保图纸既能正确显示 CAD 底图，又能完整提取路网节点（`nodes`）、有向路径（`tracks`）与业务站点（`stations`），避免导入失败或运行时出现“任务路线不可达”。

> 对应校验实现：[ndc8AgvMap.ts](../src/editor/cad/ndc8AgvMap.ts)、[agvMap.ts](../src/editor/model/agvMap.ts)、[cadReferenceStreamingDxf.ts](../src/editor/cad/cadReferenceStreamingDxf.ts)。
> AGV 产生器完整接口与运行时协议见 [agv-map.md](agv-map.md)。

---

## 1. 文件格式、空间与单位要求

| 检查项 | 要求 | 说明 |
| --- | --- | --- |
| 文件格式 | **ASCII 文本 `.dxf`** | 不支持 `.dwg`、二进制 DXF |
| 所在空间 | **模型空间（Model Space）** | 图纸空间图元（组码 `67 = 1`）会被忽略 |
| 实体形态 | **顶层基础图元** | 节点、路线、站点必须直接为 `CIRCLE` / `POLYLINE` / `LWPOLYLINE` / `TEXT` / `MTEXT`，**不能**包在块引用（`INSERT`）或代理实体（`ACAD_PROXY_ENTITY`）内 |
| 长度单位 | 优先声明 `$INSUNITS` | 常见 `$INSUNITS = 4`（毫米，换算系数 `0.001`）；未声明时按 `$MEASUREMENT` 推断，仍缺失则按毫米（`0.001`）兜底 |
| 坐标系与原点 | 保留原 CAD XY 原点 | 导出 JSON 自动换算为**米**；导入后产生器默认比例尺为 `1` |
| 文本编码 | UTF-8 或 `ANSI_936`（GBK） | 支持中文图层名、站点名与注释文字 |

## 2. 图层命名与图元结构（NDC8 规范）

所有参与路网提取的图层名必须以 **`Ndc8_`** 开头（**大小写不敏感**）。

### 2.1 速查总表

| 类别 | 图层命名规则 | 是否必需 | 允许图元类型 | 配对方式 | 写入 JSON 字段 |
| --- | --- | --- | --- | --- | --- |
| 路网节点 | `Ndc8_Point` | **必需** | `CIRCLE` | 与 `Ndc8_PointID` 按记录顺序一一配对 | `nodes[].x / y` |
| 路网节点编号 | `Ndc8_PointID` | **必需** | `TEXT` | 同上 | `nodes[].id / name` |
| 路线中心线 | `Ndc8_<路线图层名>`（非保留层） | **必需**（至少 1 层） | `POLYLINE`、`LWPOLYLINE` | 与同名加 `ID` 层按记录顺序一一配对 | `tracks[].points / fromNodeId / toNodeId / name` |
| 路线编号 | `Ndc8_<路线图层名>ID` | **必需**（与路线层成对） | `TEXT` | 同上 | `tracks[].id` |
| 业务站点 | `Ndc8_Activity_<业务类型>` | 可选（调度任务用站点号时必需） | `CIRCLE` | 与 `...ID` / `...Name` 按记录顺序一一配对 | `stations[].x / y / nodeId / businessType` |
| 业务站点编号 | `Ndc8_Activity_<业务类型>ID` | 有站点层时**必需** | `TEXT` | 同上 | `stations[].id` |
| 业务站点名称 | `Ndc8_Activity_<业务类型>Name` | 可选 | `TEXT`、`MTEXT` | 同上（缺失时回退为站点编号） | `stations[].name` |
| 保留底图层 | 见 2.5 节 | 可选 | 常规 CAD 图元 | 不参与路网拓扑，仅作底图渲染 | 无 |

### 2.2 路网节点（必需）

- **`Ndc8_Point`**：用 **`CIRCLE`** 表达节点，取圆心 `(x, y)` 作为节点坐标。
- **`Ndc8_PointID`**：用 **`TEXT`** 表达节点编号。
- **硬性校验**：
  1. `Ndc8_Point` 的圆数量必须与 `Ndc8_PointID` 的文字数量**完全一致**，按 DXF 文件中的**记录写入顺序**一一配对（不按空间距离就近猜测）。
  2. 任意两个节点的圆心坐标**不可完全重合**。
  3. 节点编号非空、长度 ≤ `128` 字符，且在同一地图 `nodes` 内**唯一**。

### 2.3 路线中心线与编号（必需）

- **路线图层**：以 `Ndc8_` 开头且不属于 2.5 节保留层的图层，图元类型为 **`POLYLINE`** 或 **`LWPOLYLINE`**。图层原名会写入 JSON 的 `track.name`。
- **编号图层**：与路线图层同名前缀加 **`ID`**（例如 `Ndc8_PS15-FW` 对应 `Ndc8_PS15-FWID`），图元类型为 **`TEXT`**。
- **硬性校验**：
  1. **端点精确匹配**：每条有效路线中心线的**首点与末点坐标必须与 `Ndc8_Point` 中某个节点的圆心完全一致**，分别决定 `fromNodeId` 与 `toNodeId`。
  2. **有向规则**：路线方向直接沿用折线顶点顺序（`points[0] → points[n - 1]`）。**不自动推断双向**；若某路段允许双向通行，必须在图纸中分别绘制正向与反向两条折线，并各自配对独立编号。
  3. **箭头 / 占位兼容**：每条有效中心线之后，允许紧跟 **0 条或 1 条**方向箭头折线或零长度退化占位线（如全顶点重合于 `(0, 0)`）；若中心线之前出现箭头，或连续出现多条非中心线折线，会报“多余或错位的箭头图元”并拒绝导入。
  4. **数量与顺序配对**：每个路线图层的有效中心线数量必须与对应 `*ID` 图层的编号数量完全一致，按记录顺序一一配对；路线层与 `*ID` 层不得孤立存在。
  5. **编号唯一性**：所有路线图层的路线 ID 非空、长度 ≤ `128` 字符，且在整张地图 `tracks` 内**唯一**。

### 2.4 业务站点（可选，调度任务涉及站点编号时必需）

当业务系统（如 MQTT 的 `task_begin_point` / `task_end_point`）下发的是**业务站点编号**而非底层路网点编号时，必须保留或补齐业务站点图层：

- **站点图层**：`Ndc8_Activity_<业务类型>`，图元类型为 **`CIRCLE`**；`<业务类型>` 会写入 `station.businessType`。
- **编号图层**：`Ndc8_Activity_<业务类型>ID`，图元类型为 **`TEXT`**；数量必须与站点圆完全一致，按记录顺序配对。
- **名称图层（可选）**：`Ndc8_Activity_<业务类型>Name`，图元类型为 **`TEXT`** 或 **`MTEXT`**；若存在，数量必须与站点圆完全一致，按记录顺序配对；名称为空或超过 `128` 字符时自动回退为站点编号。
- **节点关联规则**：
  - 每个站点圆心会优先精确匹配 `Ndc8_Point` 圆心；
  - 若未精确重合，则在 **50 mm（`0.05 m`）** 容差内查找**唯一最近**的路网节点；
  - 找不到或在容差内存在等距歧义时，导入报错。
- **命名空间隔离**：业务站点写入独立的 `stations` 数组（通过 `nodeId` 关联 `nodes`），允许业务站点 `id` 与路网节点 `id` 相同而互不冲突。

### 2.5 保留底图图层（不进入路网）

以下 `Ndc8_*` 图层会被自动排除在路网拓扑之外，但仍会作为 CAD 底图在场景中渲染（含图层颜色与标注文字）：

- `Ndc8_Text`
- `Ndc8_DrawingLine`
- `Ndc8_IgnoreFalseLine`
- `Ndc8_Reflector`
- `Ndc8_PositionMarker`
- `Ndc8_Cluster`
- `Ndc8_Group_*`
- `Ndc8_Home_*`
- `Ndc8_Point` 中的实心圆 `HATCH`（渲染为点位实心填充）

> **注意**：若图纸中有其他自定义辅助线层且不希望被当作 AGV 路线提取，**不要**以 `Ndc8_` 开头命名（或归入上述保留层，如 `Ndc8_DrawingLine`），否则会被当作路线图层校验并因缺少对应 `*ID` 图层而报错。

## 3. 数量与体量上限

| 项目 | 上限 |
| --- | --- |
| 路网节点数（`nodes`） | `4,096` |
| 路线数量（`tracks`） | `8,192` |
| 单条路线折线顶点数（`points`） | `2,048` |
| 业务站点数量（`stations`） | `4,096` |
| 编号 / 名称单字段长度 | `128` 字符 |
| 单次解析几何内存预算 | `2 GiB` |

## 4. 新 DXF 改图与修正标准流程（Checklist）

拿到一份新的或第三方 DXF 图纸后，按以下顺序修正：

1. **格式与实体清理**
   - 用 CAD 软件打开，确认全部路网内容位于**模型空间**。
   - 检查 `$INSUNITS` 单位设置（通常设为毫米 `4`），确保与图纸实际尺寸一致。
   - 若节点、路线或站点被打包在块（Block / `INSERT`）中，先执行炸开（`EXPLODE`）还原为顶层 `CIRCLE`、`POLYLINE`/`LWPOLYLINE`、`TEXT`/`MTEXT`。
   - 另存为标准 **ASCII 文本 `.dxf`**（推荐 AutoCAD 2018 / AC1032 或更低 ASCII 版本）。
2. **图层归类与重命名**
   - 路网点位圆 → `Ndc8_Point`，路网点位编号 → `Ndc8_PointID`。
   - 业务站点圆 → `Ndc8_Activity_<业务类型>`，站点编号 → `Ndc8_Activity_<业务类型>ID`，站点名称（如有）→ `Ndc8_Activity_<业务类型>Name`。
   - 行驶路径折线 → `Ndc8_<路线名>`，路径编号 → `Ndc8_<路线名>ID`。
   - 建筑墙体、货架、文字说明、箭头以外的辅助线 → 使用**非 `Ndc8_` 前缀**图层名，或放入 `Ndc8_DrawingLine` / `Ndc8_Text`。
3. **节点与编号校对**
   - 核对 `Ndc8_Point` 圆数量 = `Ndc8_PointID` 文字数量，且写入顺序一一对应。
   - 清理重复叠加的重合圆心与重复编号。
4. **路线端点、方向与箭头校对**
   - 开启 CAD **圆心捕捉**，确保每条路线折线的起点与终点严格落在 `Ndc8_Point` 圆心上。
   - 核对折线顶点方向与实际行驶方向一致；需要双向通行的路段，补充反向折线与独立编号。
   - 清理孤立箭头或连续多余箭头，确保每条中心线后最多跟 1 条箭头/占位线。
   - 核对每个路线层的有效中心线数量 = 对应 `*ID` 层的文字数量，且顺序一致。
5. **业务站点校对**
   - 核对调度系统会下发的所有站点号均已出现在 `Ndc8_Activity_*ID` 中。
   - 确保每个站点圆心与对应路网节点圆心重合，或距离严格小于 `50 mm` 且无等距歧义。
6. **导入与验收**
   - 在编辑器选中 AGV 产生器 → 点击「地图上传（DXF）」。
   - 导入成功后点击「导出地图 JSON」，核对 `nodes`、`tracks`、`stations` 数量与坐标（米）。
   - 在运行预览中验证典型任务的起终点路径是否可达。

## 6. 常见报错与排查对照

| 现象 / 报错信息 | 常见原因 | 修正方法 |
| --- | --- | --- |
| `DXF 中未找到 NDC8 路网点位和路线` | 图层未按 `Ndc8_*` 命名、图元在图纸空间或被块引用包裹 | 将路网图元移至模型空间、炸开块，并按 2.1 节重命名图层 |
| `NDC8 点位圆与编号数量不一致，无法确定点位 ID` | 手动删改了圆或文字，未同步处理配对项 | 核对 `Ndc8_Point` 与 `Ndc8_PointID` 数量并按顺序补齐 |
| `NDC8 图中有圆心重合的点位，无法唯一匹配路线端点` | 同一坐标存在重复的 `CIRCLE` | 删除重叠的多余圆及对应编号文字 |
| `NDC8 图层「...」缺少对应的路线编号` | 存在 `Ndc8_*` 折线层但没有同名 `*ID` 层（常见于误把辅助线命名为 `Ndc8_*`） | 若为路线则补齐 `*ID` 层；若仅为底图辅助线则改用非 `Ndc8_` 前缀或移至 `Ndc8_DrawingLine` |
| `NDC8 图层「...」的有效路线中心线（X）与编号数量（Y）不一致` | 某条折线首尾未精确捕捉到节点圆心，或增删折线未同步增删编号 | 用圆心捕捉修正折线首尾端点，并保持折线与编号一一对应 |
| `NDC8 图层「...」存在多余或错位的箭头图元` | 中心线前出现箭头，或一条中心线后跟了多条非中心线折线 | 清理多余/错位箭头，确保每条中心线后最多 1 条箭头或占位线 |
| `NDC8 业务站点「...」附近未找到唯一的路网节点` | 站点圆心距离最近节点超过 `50 mm`，或与多个节点等距 | 将站点圆心移动到对应 `Ndc8_Point` 圆心（或 50 mm 内唯一最近位置） |
| `NDC8 路网包含重复编号、无效坐标或无效端点` | 跨图层存在重复路线 ID、节点 ID 重复或坐标非有限数 | 检查并去重全部节点/路线/站点 ID |
| 运行时提示「任务路线：A → B 无可达路线」 | ① 任务使用业务站点号但图纸缺少 `Ndc8_Activity_*`；② 路线仅单向未画反向折线；③ 中间某段折线未连上节点 | 补齐业务站点图层、按需补画反向路线，并核对途径节点连通性 |
