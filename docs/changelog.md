# 最近完成（变更记录）

> 从根目录 README 迁出的历史变更记录，内容保持原样。

## 最近完成

- 2026-10-20：内置货格新增「留存货物」开关（每排一个）：多穿小车或堆垛机放货后，货物留在格口支撑位不再立即消失，直到设备再次取同格时接管同一货物实例。开启后该格在 fetch 驱动的货架中建立持久抑制，定时/单排同步不会删除或重复渲染；关闭时保持原有 fetch 清算/即时销毁行为。场景格式仍为 v5，旧场景缺省关闭。
- 2026-09-20：货架库存 fetch 同步新增定时全量触发：工具栏“配置 Fetch 请求”可设同步间隔（秒，默认 60、最小 10，填 0 表示只在进入运行预览时同步一次），编辑器运行预览与数字孪生发布包 Viewer 都按该间隔持续拉取，覆盖外部改库存的盲区。定时 tick 遇到在途请求（如放货单排同步）会跳过本轮，避免抢走响应代际导致格口抑制不解除、停留货箱不销毁；定时失败提示只打印一次，链路恢复后再失败会重新提示。间隔为场景配置项，随场景保存并进入发布包。
- 2026-09-20：货架格口抑制新增数据确认解除：设备取货后该格被抑制隐藏货物，此前要等同一排下次放货才恢复可见，期间外部入库的新货不显示；现在任何 fetch 响应（含定时全量）确认该格已空即自动恢复该格渲染。该排仍有待清算保留货箱时不做解除，避免与保留货箱双显；取货本身仍不触发单排同步（服务端此刻常未更新，会双显）。
- 2026-09-08：修复点击绑定选自共享库、场景模型使用工程快照时预览不命中且发布清空槽位的问题；支持同设备多个历史快照和包内子模型，保留绑定单独引用的模型资源。数字孪生 DIST 同时保留 CAD 组件与 DXF，大图 Worker 使用部署资源 URL。已有发布包需要使用更新后的编辑器重新发布。

- 2026-09-02：Toolbar 新增场景全屏按钮（运行/停止旁），`F11` 同步切换；全屏时隐藏 Hierarchy/Inspector/Project/Console，Scene 画布铺满窗口并请求系统全屏，失败时退化为窗口内最大化。运行预览可继续停止场景；发布 Viewer 右上角提供相同入口。`Esc` 或再次点击退出，返回首页前会先退出全屏。
