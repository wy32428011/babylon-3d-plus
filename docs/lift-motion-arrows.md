# 提升机与换层提升机运动箭头

更新时间：2026-10-20。

在模型的“数据驱动”面板中打开“提升机运动箭头”或“换层提升机运动箭头”，勾选“启用运动箭头”。提升机提供升降、前工位、后工位三路；换层提升机仅提供升降。旧场景默认关闭，与已有堆垛机、RGV 箭头保持一致。

## 显示与配置

十种箭头样式与现有输送线、堆垛机、RGV 共用，支持从特效库拖入样式，调整颜色、透明度、发光、流动速度和呼吸效果。默认青蓝色移动双箭头、关闭呼吸。流动速度为零时图案停止流动，设备停止后仍会淡出。

| 通道 | 位置 | 运行依据 |
| --- | --- | --- |
| 升降 | 固定立柱侧面、完整高度，按实时载货台高度留出缺口 | 驱动执行后的连续升降位移 |
| 前工位 | 对应前台面，随载货台升降 | 真实取货、台内移行或离台承接的实际位移 |
| 后工位 | 对应后台面，随载货台升降 | 真实取货、台内移行或离台承接的实际位移 |

升降优先识别模型声明的固定立柱或 `fixedNodes` 中的竖直细长部件；无固定声明时识别明确的立柱名称。不能识别时，在“升降挂点与范围 → 升降部件”填写实际固定柱的节点名或唯一尾部路径。指定运动载货台作为升降挂点会给出诊断并隐藏。升降长度、纵向及横向中心自动匹配固定立柱，可调宽度、离面距离及方向反转。

工位优先使用 `dataDriven.cargo.frontNodes/backNodes`；只有共享 `cargo.nodes` 的提升机则沿实际输送轴划分前后两半。实际轴继承原驱动的模型声明或来料/送料绑定推断，箭头不额外寻址或修改设备状态。工位可调整挂点、顶面/侧面、自动或手动长宽及偏移。尺寸使用模型局部米，保留场景实例整体缩放。

没有可靠立柱、平台几何或本帧输送轴时显示诊断并隐藏对应通道。模型部件隐藏、资源释放时也会隐藏，避免箭头悬空。方向反转仅改变箭头显示，不改变设备动作。

## 运行与发布

正常停止后沿用 120 ms 淡出；故障、`work_state=10` 急停、数据过期、绑定冲突、模型隐藏或缺少本帧有效运动结果时立即隐藏。初始化定位、换层提升机初层吸附、取货完成补齐及约束纠偏不作为连续运行。

“正向 / 反向 / 停止 / 结束预览”只预览箭头。切换模型、场景或运行模式后清除，不保存预览状态。`telemetryBinding.liftMotionArrows` 保存配置，支持撤销重做、复制、保存重开；SOURCE 和 DIST 保留同一配置，发布 Viewer 使用相同驱动与渲染路径。启用该功能后需要重新构建并重新发布，已部署包不会自动更新。

## 开发验证

- `npm run test:lift-motion-arrows`：配置、会话、编辑 store、真实专用驱动、几何与门控回归。
- `npm run smoke:lift-motion-arrows`：构建、真实编辑器 WebGL、本地 MQTT 夹具、SOURCE/DIST 打包及实际解包 Viewer WebGL。
- `npm run test:lift-motion-arrows:integration`：已有 `output/lift-motion-arrows/scene.scene.json` 和 Viewer 构建时，单独检查 SOURCE/DIST。

证据写入 `output/lift-motion-arrows/`。本地 MQTT 夹具验证不代表现场 Broker、实际业务模型包或已安装编辑器版本验收。
