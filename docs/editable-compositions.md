# 可编辑组合模型

组合由至少两个导入模型或基础几何体组成。组合库保存成员结构、相对变换、参数和固定资源包，每次放入场景都会生成独立实体。

## 操作

1. 在场景中摆好模型并多选，打开下方“组合库”，拖动工具栏中的“保存组合”按钮（带六点手柄），或从层级树拖到组合库。
2. 拖到空白区域新建组合；填写名称后保存。也可使用右键“保存为组合模型”或点击工具栏“保存组合”。
3. 从组合卡片拖回场景。单击成员默认选中整体；双击或点击 Inspector 的“编辑组合内部”调整成员，点击场景标题栏“完成编辑”或按 Esc 退出。
4. **将调整后的组合拖到已有卡片上，直接替换该卡片对应的组合。** 卡片 ID、名称及中台资源 ID 保持，内容生成新版本。
5. 整体支持移动、旋转和等比缩放；子模型可保留自己的非等比缩放。加入或移出成员沿用层级树操作，解除组合保留成员，删除组合会删除全部成员。

只保存场景不会修改库模板。更新卡片不会改动其他已经摆放的实例，也不会改变已发布 Viewer。Inspector 的“使用库中版本”会先显示增删成员预览，确认后仅更新该实例，保留整体位姿与兼容成员身份；内部布局和参数采用库版本，支持撤销。整体搬动不改变模板中的相对摆放。

模型参数、模型内部驱动定义及资源脚本保留。新实例重新生成资产编号，场景专属遥测、外部对象联动等配置会解除，并在保存时提示；原场景的绑定不变。相机、灯光、CAD、全局生成器等对象不作为组合成员。

## 同步与版本

本地组合位于配置工作区的 `SharedResources/Assets/Compositions/<id>/<revision>`。每个版本包含 `composition.json`、固定依赖、缩略图及可生成的静态 `preview.glb`。缩略图和 GLB 仅用于展示，可编辑定义是成员结构的依据。

本地保存成功后尝试同步中台；离线期间被替换的历史版本也会按顺序上传，避免旧场景失去资源。网络失败时保留本地版本，卡片显示失败状态，可通过“同步中台 / 重试”重试或取消同步。中台将组合保存在环境模型管理中的“可编辑组合模型”区域，支持详情、版本、成员结构、静态三维预览和组合包下载。

卡片替换采用版本基线检查；遇到其他编辑器已更新的冲突时保留本地内容，不自动覆盖远端。可将需要保留的结果另存为新组合。卡片提供恢复上一版本、导出组合包；组合库支持导入下载的组合 ZIP。

场景保存组合来源版本与完整成员状态；解除组合后，成员仍保留固定资源来源。普通模型“同步最新”不会覆盖组合中的固定副本。在新电脑打开场景时，按引用的固定组合版本恢复资源，不用库当前版本重置实例修改。SOURCE 包含可编辑定义和依赖，DIST 保留实际成员、参数和行为，移除本机组合目录。项目归档包含关联组合的历史版本，资源复用比较版本内容摘要。

## 升级

先部署支持组合接口的数据中台后端，并执行 Flyway `V89__editable_environment_compositions.sql`，再部署中台前端和新版桌面编辑器。旧环境模型仍使用原 GLB 协议，组合不会进入场景单例环境替换入口。

本次新增官方 `@babylonjs/serializers`，固定为与现有 Babylon 运行时一致的 `9.12.0`，用于静态 GLB 预览。参数化和交互行为仍由原成员运行时执行。
