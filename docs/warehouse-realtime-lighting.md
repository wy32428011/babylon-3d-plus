# 智慧仓储零 Blender 实时光影方案

更新日期：2026-11-27。

面向**智慧仓储数字孪生**场景，编辑器提供了一套**无需安装 Blender、改图即见效**的纯实时光影方案，涵盖一键氛围预设、三档性能画质、实时屏幕空间接触暗影（SSAO2）、仓储分层阴影过滤与移动设备底盘软影，并保持对历史场景与离线 Cycles 烘焙的完全兼容。

## 为什么智慧仓储推荐使用实时光影

1. **货架密集细碎**：立库横梁与立柱数量庞大，离线烘焙需要展开海量光照 UV，极易触发图集预算上限或远景条纹闪烁。
2. **设备与货物高动态**：AGV、RGV、堆垛机、穿梭车与动态托盘持续移动，静态间接光贴图无法覆盖实时位移的货物；实时光影能够让设备走到哪里，投影与接触暗影就跟到哪里。
3. **即改即看与零部署门槛**：实施人员调整货架布局、开关屋顶或修改灯光角度后立即生效，团队成员与发布包均无需额外安装或配置 Blender 路径。

## 快速上手（10 秒完成配光）

打开右侧**场景属性 → 光照与阴影**面板：

1. **选择一键仓储氛围**：
   - **明亮洁净仓**（推荐默认）：中性白顶光 + 柔和浅灰地坪反弹补光 + 内置 `warehouseBright.env` 环境贴图 + ACES 色调映射 + 半分辨率 SSAO2，默认关闭离线烘焙。
   - **科技暗黑大屏**：冷调深蓝底色 + 内置 `warehouseDark.env` 环境贴图 + 轻雾层次 + 保留模型自发光，突出 AGV 轨迹与货位告警高亮。
   - **室外物流园区**：高角度日光主光 + 天空盒 + 160 米级联阴影范围。
2. **切换性能画质档位**：
   - **流畅**：`performance` 阴影 + **仅地面接收阴影** + **跳过小货物与细件投影** + **移动设备底盘软影** + 关闭 SSAO2，适合超大型立库或核显电脑。
   - **标准**（默认推荐）：`balanced` 阴影（100 米覆盖）+ **跳过小货物与细件投影** + **半分辨率 SSAO2**，在清晰度与帧率间保持均衡。
   - **高清**：`quality` 级联阴影（120 米覆盖）+ **高精度 SSAO2**，适合展厅独立显卡大屏。
3. **单物体快速微调**：
   - 选中屋顶、货架或设备后，可在右侧**阴影与光照**中直接勾选或取消**投射阴影** / **接收阴影**（例如关闭厂房屋顶投射阴影，避免俯瞰视角将库区内部压暗）。
   - 该开关自动开启 `respectEntityShadowOverrides`，在全场景自动阴影模式下依然精确生效，并支持 `Ctrl+Z` 撤销/重做。

## 核心能力说明

### 1. 内置工业仓储环境光（`.env`）

项目在 `src/runtime/babylon/assets/` 内置两套由 `scripts/prepare-warehouse-builtin-env.mjs` 预过滤生成的高动态环境贴图（随 Editor 与 Web Viewer 离线打包，不依赖外网）：

- `warehouseBright.env`：工业天窗与均匀 LED 顶灯带反射，浅灰地坪向上反弹，适合白色/浅色洁净厂房与物流仓。
- `warehouseDark.env`：深蓝灰工业环境与冷白灯带高光，适合科技暗黑风格大屏。

### 2. 实时接触暗影（SSAO2）

`SceneSsaoRuntime` 基于 Babylon.js 原生 `SSAO2RenderingPipeline` 实现（配置项为 `sceneSettings.appearance.ssaoMode`: `'balanced' | 'high'`，缺省关闭）：

- 在货架立柱接地处、托盘与层板接缝、AGV 车底等几何交界实时生成柔和暗边，替代传统离线烘焙中的静态 AO 立体感。
- `balanced` 档采用半分辨率计算（`ssaoRatio: 0.5, blurRatio: 0.5`）并按仓储米制尺度调优（`radius: 1.1`、`maxZ: 150`）。
- 若运行环境不支持 WebGL2 或 MRT（例如 Node `NullEngine` 或受限浏览器），系统会安全降级跳过，不报错也不注册多余管线。

### 3. 仓储分层阴影过滤与移动底盘软影

在 `managementMode: 'automatic'` 下，可通过以下可选字段减少大库冗余阴影开销（缺省全部关闭，不改变旧场景）：

| 配置字段 | 作用 |
| --- | --- |
| `receiverScope: 'ground-only'` | 仅环境底座与地面接收阴影，货架/料箱表面不再逐像素采样阴影贴图 |
| `skipGeneratedCargoCasters: true` | 跳过运行期动态生成的货物/托盘投影，保留 AGV、堆垛机、主货架投影 |
| `skipSmallCastersMeters: 0.8` | 忽略最大边长小于阈值（米）的静态细小零件投影，消除远景细碎锯齿 |
| `respectEntityShadowOverrides: true` | 允许在自动阴影模式下保留个别对象/部件的显式 `投射阴影` / `接收阴影` 例外 |
| `mobileBlobShadows: true` | 由 `MobileBlobShadowRuntime` 在 AGV/RGV/穿梭车/叉车/堆垛机底盘下方绘制轻量径向软影贴片 |

### 4. 美术 `.glb` 导出推荐规范

对于静态厂房外壳、地坪与月台模型，推荐遵循以下轻量化约定：

1. **屋顶独立命名与分组**：将厂房屋顶、天花板独立成层或独立实体，导入后在右侧栏关闭**投射阴影**或隐藏，以免遮挡库内光照。
2. **可选静态 AO 写入标准 glTF**：如希望墙角或立柱更具实体层次，可在建模软件烘焙极简 AO 后直接写入标准 glTF 材质的 `occlusionTexture` 通道，Babylon.js 原生即刻读取，无需编辑器额外配置或启用离线烘焙。
3. **动态设备保持单向朝前与接地原点**：AGV、叉车等移动设备的模型底面贴近局部 `Y = 0`，便于底盘软影贴片精准贴合地面。

## 高级离线烘焙与旧工程兼容

- **旧工程零破坏**：缺失新字段的旧工程按原有逻辑读取渲染，不自动启用 SSAO2、过滤规则或覆写任何已有灯光与阴影配置。
- **高级入口保留**：仍需使用 Cycles 静态间接光的重点展厅项目，可点击「高级光照与离线烘焙（Blender）…」进入完整四页签管理器；不使用烘焙时（`bake.enabled = false`），发布与导出均不要求本机安装 Blender。
- **发布模板能力校验**：启用 `ssaoMode`、仓储阴影过滤或内置仓储 `.env` 的场景，发布时会通过 `viewerTemplateCapabilities` 确认 Viewer 模板支持对应能力；发布前请确保已完成 `npm run build:viewer`。
