# 实现经验

## 场景模型总量应与渲染裁剪分离

- 触发条件：统计全场模型面数、实例数量等内容总量，场景使用逻辑阵列、共享源几何和视锥裁剪。
- 原因：`scene.meshes` 可能移除脚本宿主，`thinInstanceCount` 可能只保留当前视锥可见实例；渲染集合不代表完整场景。双面/阴影重复绘制也不代表新增几何。
- 修复：从业务登记及完整逻辑实例累计有效源几何；生成物和环境分别纳入，模板/代理去重，计数随结构或参数变化失效。
- 防止回归：覆盖隐藏父组、相机移出视野、参数变体、生成组合和货箱增删；总数不得随纯相机操作变化。

## 新场景会话需要首份运行时快照

- 触发条件：重开同一文档 ID，编辑器清空运行快照，运行时按数值去重通知。
- 原因：文档 ID 与统计值可能均不变，运行时不再回调，新会话会一直停留在统计中。
- 修复：同步后主动发布当前快照，并以场景会话校验异步写回。
- 防止回归：验证空场景及已有模型场景按同 ID 重开，统计仍从加载态进入正确结果，且不改变文档或撤销历史。

## 去掉强制世界矩阵计算必须覆盖同帧再次同步

- 触发条件：为减少编辑辅助标记的稳态成本，将 `computeWorldMatrix(true)` 改为默认调用。
- 原因：Babylon 会按相同 renderId 快退；同一帧内父级或节点再次改变时，单纯依赖默认调用可能留下旧矩阵。
- 修复：缩放相同时不写入，使用 `computeWorldMatrix(!node.isSynchronized())`，只在真实失同步时强制刷新。
- 防止回归：覆盖同 renderId 内重复 `sync`/`syncPresentation`、父级变换、相机与视口变化；断言读取 `worldMatrixFromCache`，避免测试自身补算掩盖遗漏。

## DOM 样式去重需要考虑浏览器规范化

- 触发条件：逐帧比较并写入颜色、阴影或变换样式。
- 原因：浏览器可将 `#rrggbb` 规范化成 `rgb(...)`，直接比较输入字符串与 DOM 值会继续重复写；只记输入又可能漏掉外部改动。
- 修复：同时保存请求值与应用后的实际值，两者都一致才跳过，缓存按样式对象弱引用保存。
- 防止回归：验证规范化颜色在稳定帧无写入，外部样式改动能纠正，动态位置、尺寸和隐藏恢复仍逐帧生效。
