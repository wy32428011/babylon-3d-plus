# 场景主题

在底部 **主题库** 点击主题卡片，或将卡片拖入场景。主题应用后显示对应名称及场景属性，可调整背景、环境受光、底光和主光颜色、环境反射、曝光、对比度、模型发光光晕、可选泛光及距离雾。主光方向、强度、补光和阴影浓度沿用下方“阴影”区域。

| 主题 | 标识 | 默认效果 |
| --- | --- | --- |
| 科技蓝夜景 | `tech-blue-night` | 冷蓝底光与清晰夜景，沿用原有默认参数 |
| 工业日光 | `industrial-daylight` | 浅蓝灰背景、中性白光和较高角度主光，无主题雾 |
| 石墨中性 | `graphite-neutral` | 石墨灰背景、银白主光和适度补光，无主题雾 |
| 青绿夜景 | `teal-night` | 深蓝绿背景、青绿主光、冷色补光及轻微距离雾 |
| 暖金黄昏 | `warm-gold-dusk` | 暖灰背景、低角度暖金主光、冷色补光及轻微暖雾 |

四套新主题默认采用“接受场景照明”，隐藏天空盒背景并关闭全画面 Bloom。新建场景仍保持当前配置，不自动套用主题。原有未实现的占位卡片继续禁用。

应用或切换主题是一条撤销命令；重复应用未调整的同一主题不会增加实体、灯光或历史记录。手动修改后卡片显示“当前使用 · 已调整”，“恢复主题默认值”只恢复当前主题的参数。停用主题恢复普通渲染方式，保留当前阴影参数；若要回到应用主题之前的完整参数，使用撤销。运行预览、只读、场景准备中或阴影烘焙期间不能通过主题入口修改配置。

## 照明与兼容行为

- 主题创建一盏运行时主方向光并调整现有内置补光，接管场景实体的半球光和方向光；这些实体的数据和原始显隐设置保留，停用主题后重新生效。点光源继续独立照明。
- 环境默认采用“接受场景照明”，保留模型纹理与材质质感；可切回“保持原貌”。未应用主题的旧场景继续使用原有环境光照隔离规则。切换和调参复用已加载 GLB。
- 在模型库放置点光源，在灯光属性点击“暖白作业灯”，再按门口、装卸区的实际位置调整。该快捷设置提供暖色、强度、20 m 范围及“夜间保持”行为，不自动推断灯具位置。旧灯光字段缺失时保持历史行为；主动设置“夜间保持”的灯不被昼夜组件调暗。
- 五套主题均为固定氛围，生效时接管原来的昼夜亮度动画；停用主题后恢复该组件。显式环境雾组件优先于主题雾，关闭该组件后恢复当前主题的雾参数。
- 主题中的“显示天空盒”只控制背景球体，已配置且启用的天空盒仍提供环境照明与反射。主题不自动下载或替换 HDR/EXR 资源，环境反射强度受“阴影”区域的环境上限约束。
- 模型自发光继续复用已有 GlowLayer，可调整其光晕强度；可选 Bloom 是全画面的高亮泛光，默认关闭。发光特效不自动照亮附近建筑，需要实际灯光或光照贴图。业务特效、告警颜色继续由相应组件控制。
- 阴影模式沿用场景原设置。改变主题主光方向后，旧静态阴影按已有规则过期，需要更新阴影。新受光模式兼容实时阴影及静态遮罩；历史彩色烘焙贴图保留已合成阴影，原先写入贴图的明暗无法自动分离。

## 保存与发布

场景保存主题标识、版本和全部实际参数快照，而不是只保存主题名称。后续预设更新不会自动修改已保存场景；主题参数和灯光扩展字段支持撤销重做、保存重开及 SOURCE/DIST。Viewer 使用同一运行时，已有线上包需重新构建并发布才能获得新功能。

内置五套主题，不包含自定义主题入库、独立主题导入导出、自动布灯、透明建筑、线框材质或实时地面倒影。主题不修改设备业务状态和告警配色。

## 验证

```powershell
npm run test:scene-theme
npm run typecheck
npm run smoke:scene-theme
npm run build
node_modules/.bin/electron.cmd tests/digitalTwin/sceneThemePackages.integration.mjs
node scripts/smoke-scene-theme-viewer.mjs
node scripts/smoke-scene-theme-skybox.mjs
```

可选使用已有本地模型生成五套主题的编辑器和预览截图：`node scripts/smoke-scene-theme-presets.mjs --model "C:/path/to/factory.glb"`。脚本只读取模型，采用固定的包围盒适配相机，不保存或发布真实项目；结果位于 `output/playwright/scene-theme/real-factory`。

浏览器验收使用本地 PBR 厂房夹具、真实主题卡片和场景属性，通过隐藏环境前后的差分像素区分模型与背景，结果保存到 `output/playwright/scene-theme`；双包测试结果保存到 `output/scene-theme/packages-result.json`，实际 DIST Viewer 的截图和结果保存到同一目录。这些测试不代表已经部署到真实中台项目或完成正式安装包验收。
