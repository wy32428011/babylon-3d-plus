# 当前功能

> 从根目录 README 迁出的完整功能清单，内容保持原样。

## 当前功能

- 可导入开场包：开场素材、默认参数和分镜可独立打包，导入工程并应用后才显示该包配置；未导入不生成默认参数。独立开场不接管三维相机或停止业务运行，缺失或不兼容开场可明确降级而不阻断有效三维发布。场景分别保存文案、飞线、时长与素材替换，支持固定版本、保存重开及 SOURCE/DIST；旧内置参考开场继续兼容。包格式、支持范围与操作见 [开场插件包](opening-packages.md)。

- 场景属性分组支持独立展开、收起：点击各大项标题切换，默认展开，可同时展开多个分组；收起时保留输入和编辑状态，只读或预览模式下仍可切换展开状态。

- 参考版开场动画：按 `zd_digital_twin_opening.html` 的画面播放“旋转地球 → 地球展开 → 全球业务 → 中国全景 → 江苏高亮 → 国内业务 → 江苏 → 无锡 → 惠山 → 已保存场景视角”，默认 9 阶段共 62 秒，开关默认关闭。各段时长可独立配置，全球/国内停留支持 0 秒；参考图 40/34 条飞线使用画面 UV，支持增删、预置与自定义。面板提供品牌公司文案、画质、界面显示、跳过、动效、呼吸和结束行为。业务场景持续运行，最后短淡出显露原相机；支持撤销、保存重开及 SOURCE/DIST，旧配置保留显式零值和历史经纬度档案。使用方法与边界见 [开场动画](geographic-opening.md)。

- 开场科技呼吸：参考图的动态光圈、星点与定位效果由同一播放时钟驱动，暂停时冻结；默认强度 65%、周期 4 秒，可关闭或设为零。减少动态直接展示抵达画面并短暂交接。底图中已烘焙的公司文字和行政注记不随文案配置改变；已发布 Viewer 需要重新发布才能使用新版动画与素材。

- RGV 运动箭头：在“数据驱动 → RGV 运动箭头”中配置行走、前工位和后工位三路特效。行走沿固定双轨中心正上方覆盖全长，前后台面箭头随车移动；复用输送线十种样式，支持独立预览、诊断、撤销、复制、保存和 SOURCE/DIST。默认关闭，正常停止短淡出，故障、断流或绑定冲突立即隐藏；使用方法、模型声明要求与验证入口见 [RGV 运动箭头](rgv-motion-arrows.md)。

- 堆垛机运动箭头：在模型“数据驱动 → 运动箭头”中启用，行走、升降、前叉和后叉按三维运行时实际执行的运动显示方向；行走箭头覆盖固定轨道全长、不随底盘平移，升降箭头按载货台当前高度留出随平台移动的缺口；支持特效库十种箭头样式、挂点与范围校准、四路独立预览、撤销、复制、保存及 SOURCE/DIST。默认关闭，旧场景保持原貌；正常停止约 120 ms 淡出，故障、急停、断流或绑定冲突立即隐藏。使用方法、发布升级要求与验证入口见 [堆垛机运动箭头](stacker-motion-arrows.md)。

- 六类输送方向箭头特效：特效库新增单一直线、连续流向、分段式、宽幅带式、双列前进和高速流动六种发光箭头及缩略图。可独立拖入场景调整长宽、颜色、强度、速度、不透明度、数量和反向，也可拖入输送线“表面箭头”样式框；支持保存、撤销、复制和 SOURCE/DIST。使用说明见 [输送方向箭头特效](conveyor-arrow-effects.md)。

- 输送线表面箭头：输送线默认启用“移动双箭头”并关闭呼吸效果（已保存的显式设置保持），可将特效库的十种内置箭头拖入属性样式框，继承模型方向映射或单独指定 MQTT 点位及正反停编码。支持部件校准、范围/颜色/流速/呼吸调整和临时预览；拖放只改当前模型样式，参数支持撤销、复制及保存。停止、故障或过期时隐藏，已有 Viewer 需重新构建发布；使用方法与验证边界见 [输送线表面箭头](conveyor-surface-arrows.md)。

- 可编辑组合模型：将两个及以上模型拖到组合库空白处新建；调整后拖回已有卡片可替换同一资源。组合支持整体操作、内部编辑、独立实例、历史版本与中台环境模型管理同步，并保留 SOURCE/DIST 和项目归档链路。使用方式及升级要求见 [可编辑组合模型](editable-compositions.md)。

- 场景主题：主题库中的“科技蓝夜景”支持点击或拖入场景，一次应用冷蓝底光、主光、环境受光、曝光和距离雾，并可在场景属性微调、恢复默认或停用。灯光属性补充颜色、点光范围和暖白作业灯快捷设置。参数支持撤销重做、保存重开及 SOURCE/DIST，旧场景默认保持原貌；新版 Viewer 需重新构建发布。使用方式、兼容行为和验证命令见 [场景主题](scene-themes.md)。

- 环境模型建筑特效：轮廓、棱线、发光、扫光、高度渐变、全息、透视和溶解生长的“绑定目标”现在可选择“环境模型”；场景属性的环境区域也支持从特效库拖入，自动创建同一种绑定。切换建筑外观类型保留环境绑定，调参无需重载 GLB；配置随普通特效实体保存、撤销和发布，清除环境后保留绑定并在环境恢复时重新应用。


- 数字孪生特效库：新增建筑材质与结构、区域扫描、三维路径、空间数据和环境及设备报警类 43 个可配置组件，并提供现有告警、图表立标、点击信息卡与镜头巡检的复用入口。旧雷达、定位光柱、火焰、烟雾从新建入口隐藏，旧场景继续兼容；输送方向箭头、移动双箭头及管线流动箭头已恢复库入口，可拖入输送线表面箭头样式框。详见 [特效组件与 44 项示意映射](digital-twin-effects.md)。配置支持撤销、复制、保存重开及 SOURCE/DIST；新版运行时需重新构建并重新发布。
- 特效详细配置与数据绑定：61 种可见独立 EFF 中，52 种提供按类型登记的 367 项专用参数，恢复的三种箭头沿用通用参数，六种新输送箭头提供专用尺寸与外观面板，并支持模型库模板拖入、场景/环境目标、数据源与字符串资产编号匹配、MQTT/中台托管 HTTP、字段映射/空间数据集、条件触发和运行诊断。路径及区域可直接在场景绘制；实时值只作用于运行副本。旧特效需显式启用详细配置，旧场景仍兼容。操作与发布说明见 [特效详细配置](effect-configuration-v2.md)。
- 目标跟随模型类型：允许编辑场景零实例，运行时从场景模型、生成器输出及库存薄实例中定位；支持实例来源、生成器范围、资产/容器/承载设备编号及运行时选择。目标加载后跟随，消失时保持镜头，同业务身份重建后恢复；会话选择不写入场景，类型引用随 SOURCE/DIST 的实际生产者资源一起迁移。详见 [类型跟随与数据绑定](effect-configuration-v2.md)。


- 光墙围栏：从特效库添加沿建筑外围的闭合动态光墙，底部明亮、向上逐渐透明。支持颜色、高度、透明度与向上流动速度（0 为静止），默认 10 × 8 米矩形，可按长宽生成矩形或输入 3–128 个局部 X/Z 轮廓点贴合不规则建筑。轮廓首尾自动闭合，拒绝自交、重叠及无效点；用变换工具摆放，缩放会同时改变实际高度。参数与轮廓支持撤销、复制、保存重开及 SOURCE/DIST；Viewer 使用同一材质且无需额外纹理资源，已有发布需要重新发布。轮廓文本点击“应用轮廓”后才进入场景保存。

- 光墙围栏验证：`node --experimental-strip-types --test --test-concurrency=1 tests/editor/lightWallFence.test.ts tests/editor/lightWallFence.integration.test.mjs tests/runtime/lightWallFence.test.mjs`；编辑器 WebGL 回归运行 `node scripts/smoke-light-wall-fence.mjs`。完成 `npm run build` 后运行 `node node_modules/electron/cli.js tests/digitalTwin/lightWallFencePackages.integration.mjs`，再运行 `node scripts/smoke-light-wall-viewer.mjs` 验证实际 DIST。上述使用本地示例建筑/轮廓和平台配置 fixture，不代表已部署至真实业务场景。

- 发布 Viewer 版本缓存：首次加载把场景、资源清单、模型、外链纹理、脚本及天空盒文件存入 IndexedDB；同版本刷新复用文件，并复用 Draco、Meshopt 几何解码及 KTX2 纹理转码结果，HDR/受支持 EXR 沿用已有天空盒解码缓存。每次发布生成独立 `cacheRevision`，刷新先读取最新配置，新版本自动重新加载；下载期间发生发布变更会提示重新加载，避免混用版本。项目运行配置、启停、业务接口与 MQTT 仍实时读取。浏览器刷新仍需重建场景、运行脚本、解析普通 PNG/JPEG、上传 GPU 及预过滤，不能保证零初始化。缓存按部署地址、发布标识、解码参数和引擎版本隔离，KTX2 额外区分显卡能力；资源与模型/纹理解码缓存总计上限 1 GiB、4096 条，单条超过 512 MiB 不缓存，达到限额时淘汰较久未使用项。浏览器清理存储、空间不足或禁用 IndexedDB 时自动恢复正常加载。普通 HTTP 内网可用，无需 Service Worker；新版 Viewer 兼容缺少版本标识但具有完整资源哈希清单的旧格式配置，按清单指纹缓存模型和天空盒；无完整哈希时保持联网读取。已部署的旧 Viewer 需要使用新版编辑器重新发布后才能生效。验证命令和边界见 [发布 Viewer 缓存](published-viewer-cache.md)。

- 区域视角：场景属性新增独立的“区域视角”列表，支持保存多个视角、定位、重命名、更新为当前视角、拖拽排序、上移/下移和删除，并支持撤销/重做。按住名称左侧手柄拖到目标视角的上方或下方，插入线提示落点，松开鼠标即可调整顺序；一次拖拽可一次撤销，也可使用“上移 / 下移”按钮。保存并重新打开场景后顺序保留，重新发布后大屏区域视角下拉框沿用该顺序。调整已保存视角时先定位，再旋转、平移或缩放相机，最后点击“更新为当前视角”；排序、更新与重命名保留稳定 ID。每个场景最多 256 个视角，名称最长 80 字且不可重复，保存透视/正交投影和完整轨道位姿；原有初始视角与场景级可视距离独立保留。

- 区域视角随场景文件及 SOURCE/DIST 保存。大屏组件库中的“区域视角下拉框”读取当前 Viewer 实际加载版本的视角，选择后切换相机；修改本地视角后需要保存、重新发布数字孪生并重新加载大屏。切换会停止占用相机的巡检、漫游与相机回放，保留实时数据和设备动画。手动调整相机后清除下拉选中状态，可再次选择原视角恢复。

- 区域视角回归：`node scripts/smoke-region-views.mjs` 验证 Store、撤销、序列化与真实 Babylon 相机控制，并生成 `output/region-views/scene.scene.json`；完成 `npm run build` 后可运行 `node node_modules/electron/cli.js tests/digitalTwin/regionViewPackages.integration.mjs` 检查双包中的实际场景条目。上述本地测试不代表已向业务项目部署。

- 绑定大屏关闭联动：设备点击打开的中台大屏关闭后，按来源 Runtime、会话和选择标记取消设备/货格选择及对应高亮，保留相机、巡检、漫游和宿主三维实例；快速切换设备时旧关闭不会清除新选择。需先部署支持 `clearSelection` 协议的中台前端，再升级 Viewer 并重新发布数字孪生场景；旧发布包继续支持关闭大屏，但不具备自动取消选择能力。

- 性能采样与漫游缓存：性能运行和 Viewer 诊断报告增加真实逐帧 P50/P95/P99 及遥测阶段耗时；普通运行不启用额外逐帧采集。漫游复用未变化环境的碰撞索引与邻域代理，无漫游出生点的编辑场景延迟人物加载。原有画质、碰撞精度、参数脚本和设备动作规则保持；实测条件、验证边界及使用方式见 [极致性能优化实施记录](extreme-performance-implementation.md)。

- 模型统一与自动发布准备：打开中台项目、本地场景、手动和自动同步均以当前目标中台确认的稳定资源 ID 为资源权威，保留实体、同 key 的实例参数值、资产编号及场景业务绑定，参数定义和包内部执行规则采用新版；同包子模型按包内路径分别匹配。本地打开先替换最新模型，再恢复其他本地依赖；未配置中台仍使用原有本地恢复。发布自动对齐 SOURCE 全部场景，非入口场景使用临时运行时校验并按需重烘焙，不覆盖其原文件；SOURCE 与 DIST 使用一致快照。资源修订或快照冲突最多自动尝试三轮，每轮使用新上传请求，工程版本冲突仍保留原处理。发布期间暂停后台场景同步，取消只中断对应请求。参数类型、范围、节点及参数纹理冲突仅在日志中提示，直接应用新版模型；无法取回或身份不明确等真实资源错误仍报告失败，不将不完整资源标记为发布成功。

- 发布资源快照协议：配套数据中台后端提供本次引用资源的可信快照校验，避免无关全局资源变动打断发布；后端升级需执行对应数据库迁移。连接旧后端时保留全局修订前后校验及有界自动重试。已发布内容不会自动改变，升级后需要重新发布。开发回归使用 `npm run test:unified-model-sync`；真实 Electron 非入口场景渲染验证使用 `node tests/digitalTwin/publishSceneSnapshots.integration.mjs`。

- 场景连续加载与全库同步：一次打开会持续显示同一个加载层，直到本轮资源更新、设备/环境初始化和实际首帧完成；资源加载失败或超时不会标记为 100%，可重试或显式选择“保留资源问题并继续编辑”。场景准备结束后自动后台同步中台全部普通、组合和环境模型，包括未绑定模型；模型库/环境库也提供“同步模型库”入口。自动和手动“同步模型库”都会在全库同步后以同一事务替换当前场景匹配的模型，“同步场景模型”则只更新场景引用资源。各同步入口均采用新版参数定义，新增用默认值、删除直接移除、同 key 保留各实例保存值。右上角资源问题提示可关闭并从“资源问题 · 查看详情”重新展开；模型/环境同步提示支持关闭，成功提示在非悬停、非键盘操作时自动收起。关闭提示不清除资源问题或发布校验。

- 主动同步替换与参数保留：模型库和环境库中的“同步模型库”会等待普通、组合和环境全库同步，再将新版资源应用到当前场景；“同步场景模型”用于定向更新，本地场景也可使用。替换保留实体 ID、摆放、资产编号和业务绑定。参数定义、默认值、范围、绑定及执行规则全量使用新版：新增参数使用新版默认，删除参数及其旧值直接移除，同 key 保留场景显式保存值（包括 0、false、空串和向量）；未保存值使用新版默认。同 key 类型/范围变化不重置数值，差异只写日志，不弹确认或阻止模型替换与发布。不能执行的声明式参数绑定/规则或参数纹理仅隔离对应效果，后续绑定继续。保存重开不再按新范围清洗历史值；用户主动编辑时只校验实际改动字段。下载期间场景变化会重新校验最新配置，连续变化则保留编辑并提示重试；场景替换支持一次撤销/重做，并等待脚本与真实首帧后结束加载。已同步资源按固定版本引用，保存后保留到场景文件，SOURCE/DIST 继续使用同一份配置。本地场景中的历史来源标识、失效工作区路径和缺少身份的模型/点击槽位，先按资源类型、ID 与包内路径向当前中台确认；确认并同步成功后统一替换并回填身份，保存重开保留。无法识别资源 ID、身份与包内引用矛盾或当前中台没有对应资源时仍保留原引用并提示；无关模型库下载问题单独提示，发布会自动重新同步并检查当前场景资源问题。

- 模型加载准备优化：场景资源按 ID 隔离可变缓存，最多 4 个普通/组合资源并行，环境同步同时启动；共享库索引和同一 ID 的提交仍串行保护。历史固定版本路径和实例参数保持，首次使用新的可变缓存可能重新下载一次。环境节点按父节点优先冻结，模型节点查询限定在当前子树，减少大场景重复矩阵更新和全场景扫描；首帧就绪按实际帧前/帧后事件确认，避开固定轮询尾延迟；不改变几何、纹理、参数化脚本及动画。定向回归运行 `npm run test:scene-loading`，CPU 准备基准运行 `node --experimental-strip-types scripts/smoke-model-load-preparation.mjs`；当前构建的 Electron 窗口回归运行 `npm run smoke:scene-loading`。基准和本地测试服务不替代实际部署场景验收。

- 历史场景模型重新关联：原模型 ID 被当前中台明确返回不存在时，普通/组合模型按相同资源类型、规范化资源名和相同主文件名寻找唯一候选；资源目录中的固定版本布局哈希及“场景保留版”后缀不参与名称比较。候选仍须通过详情名称、实际主文件和模型包校验，成功后更新全部实例与点击设备槽位，关联变化只写日志。无候选、多候选或包内子模型不能确定时保留原引用并报告原因，其他可确认模型继续同步；网络、权限和下载错误不会触发按名称改绑。本地打开的后续图片、天空盒等资源恢复异常不会丢弃已经完成的模型更新，未恢复资源仍保留具体问题；取消或切换场景不会提交旧任务结果。

- 发布场景慢加载：超过 120 秒显示加载较慢提示并继续等待完整资源和真实首帧；持续 5 分钟没有资源或阶段进展才阻断，并提供“重新加载场景”。模型、参数脚本、环境及天空盒的真实错误仍阻断，失败结算不会冒充 100%。加载层显示天空盒下载字节及处理阶段，HTTP 内网部署也支持保留 SHA-256 校验的天空盒持久解码缓存。修复发布 Viewer 后需重新发布数字孪生场景。

- 大型场景加载：中台项目先完成最新资源事务，再启动 Babylon 初始化，避免 SOURCE 与更新资源重复加载。带参数脚本的模型复用不可变源容器，但为每个实体创建独立几何、材质和动画状态；源缓存限制为 16 个空闲条目、128 MiB。外置脚本并发读取、编译共用进行中任务，初始化按时间片调度，脚本文本、参数注入及动画规则保持。天空盒下载、解码和预过滤显式跟踪，不再向 Scene 注册取消后无法清理的隐式等待项；编辑器与 Viewer 都等待当前天空盒和实际首帧后结束加载。

- 天空盒解码缓存：常用 HDR 与 PIZ/RAW/RLE EXR 的解码、立方体转换进入最多 2 个 Worker；未支持的压缩类型保留原解码路径。持久缓存按源 SHA-256、分辨率、Babylon 版本和算法版本隔离，六面内容逐一校验，限制为 8 条、128 MiB，损坏记录自动重算；保持 Float32、原分辨率和 4096 采样预过滤。`SceneRuntime.getPerformanceMetrics().loading` 可读取模型、环境、天空盒各阶段和脚本缓存诊断。真实中台回归可运行 `node scripts/smoke-real-project-loading.mjs --url <中台地址> --project <项目名称> --cold 3 --warm 10`，脚本使用独立临时工作区；`--executable <exe路径>` 验证安装产物，`--profile` 额外采集 CPU 与资源时序。

- 数据中台场景最新模型：从首页打开中台项目时始终下载其有效 SOURCE 并覆盖本地工作副本，覆盖前保留本地差异备份。场景里的历史服务地址标识不再阻断打开，按当前项目绑定的中台及稳定资源类型、ID、包内路径重新关联普通、组合与环境模型；实体参数、资产编号、摆放和业务绑定保持。资源按 ID 分组更新，下载失败、实际脚本执行异常只影响对应组：保留或恢复场景自带的快照，成功组继续使用新版。场景资源查询、应用和首帧检查连续进行，完成后可以编辑；同步应用时保留最新编辑内容，存在资源问题时显示可展开、复制的非阻塞提示并支持重新同步。带问题的场景可以保存，但发布前必须解决资源问题；成功同步及首帧校验完成后才清除发布保护。缺少有效远端包的已有工程不会覆盖为空场景。旧版本缓存保留，不自动淘汰。回归运行 `npm run test:scene-model-update`；Electron/HTTP/SOURCE/DIST/Viewer 验证运行 `npm run smoke:scene-model-update`；打包程序验证运行 `node scripts/smoke-packaged-remote-scene.mjs <exe路径>`。

- 本地场景发布归属：独立场景文件不继承上次工程或模型缓存的绑定；真正位于已绑定工程内的场景继续使用该工程的中台来源。发布窗口显示实际服务地址和工程目录，预检、资源恢复和发布使用同一目标；切换场景或配置后需要重新预检。跨中台的同 ID 项目按 `Platforms/<来源哈希>/Projects/<项目ID>` 隔离，同源有效旧 `Projects/<项目ID>` 目录仍可复用，旧绑定不自动迁移或改写。预检不创建工程，确认发布后才准备目录；发布期间不能切换工程或中台配置。
- 发布目标资源身份：发布前分类核验普通、组合和环境模型在目标中台是否存在，缺失或响应身份错误时显示资源 ID 与受影响实体，并在保存、打包和上传前阻止提交。跨中台迁移仅使用工作区 `.babylon-editor/publish-resource-mappings.json` 中已审核的目标来源、旧 ID、原内容修订及新 ID 映射；下载后再次核对完整修订，不按同名模型自动替换。身份迁移保留实体、阵列、参数和脚本配置，更新目标来源描述符并重新计算 SOURCE 快照。
- 发布前资源补全：发布时检查模型文件、脚本及生成器完整包引用；已有同版受管包只修正失效路径，真正缺失的模型按稳定 ID 从已确认的中台恢复。旧工程内可读的天空盒自动校验并导入当前受管缓存，缺失的中台天空盒按稳定 ID 或内容指纹恢复。模型与天空盒结果一次性、可撤销地回写场景，再生成 SOURCE 和 Viewer；无法确认对应资源或完整校验失败时仍停止发布。
- 本地发布资源兼容：未绑定场景的普通/组合与环境模型统一同步到工作区 `SharedResources`；发布同时兼容同一工作区早期 `Assets` 缓存，并继续校验资源完整性及目录边界。新导入的 DXF 原图保存为项目 `Assets/Cad` 内的独立副本；数字孪生发布的 SOURCE 和 Viewer DIST 均忽略 CAD 组件及 DXF 文件，缺失原图不会阻断发布；本地场景保留 CAD，发布包重新打开不包含 CAD。

- 本地场景资源恢复：从“打开场景文件”或“最近场景”打开时，先校验模型、脚本、环境、天空盒、生成器和点击绑定等依赖，再按已授权工作区及同版内容指纹恢复失效路径，完整恢复后才开始 Babylon 初始化。共享模型固定为独立版本副本，后台全库同步只更新资源库；本地场景使用“重新检查场景资源”显式重试。原环境版本找不到而当前中台有其它版本时，界面展示旧/新文件修订、大小和 SHA-256，仅在用户点击“使用当前中台环境版本恢复”后接受该精确版本；下载期间版本改变会再次阻断。恢复保留实体、参数、摆放、脚本及发布绑定，先在内存中整体提交，保存/另存后才写场景文件。未配置或离线时，可用的本地资源仍可加载；缺失或歧义资源展示具体路径。定向回归运行 `npm run test:local-scene-recovery`。

- Electron 桌面窗口：通过 Electron 主进程启动独立桌面应用窗口。
- 首页启动台：进入五面板编辑器前会先显示首页；左侧“最近项目”通过 Electron 主进程从可配置的数据中台 `POST /api/v1/projects/query` 拉取业务项目列表，支持按项目名称进行服务端搜索，展示数字孪生工程版本、项目更新时间和最新发布时间，并打开该业务项目当前绑定的数字孪生工程；右侧继续显示本地最近场景，并保留新建场景、打开项目目录和打开场景文件等入口。本地最近记录由主进程保存到 `recent-workspaces.json`，并兼容旧版单项目 `recent-project.json`。
- 项目退出清理：从编辑器返回首页或在首页取消数据中台项目加载时，会取消并等待旧项目打开和资源同步任务结束，清除当前业务绑定、项目根目录、共享资源挂载、同步进度及重试上下文；返回首页还会重置场景、选择和撤销历史。后续项目使用自己的发布上下文。已保存工程、磁盘绑定、共享缓存文件、服务地址、工作区配置及最近记录保留；发布过程中不能退出，未保存修改仍需确认。
- 数据中台发布：Toolbar 提供 `发布到数据中台`，桌面端是数字孪生工程编辑和版本发布的唯一入口。发布会先对当前场景生成一次幂等合批快照并保存，再由同一份场景内容生成包含全部场景与实际引用资源的 SOURCE ZIP、自包含 Viewer DIST ZIP，不会在各阶段重复规划合批；随后按分片断点上传并在数据中台创建工程版本、发布记录及 nginx 部署。SOURCE 源工程包保留非 CAD 的场景编辑内容、烘焙阴影 PNG/共享贴图引用和实际引用的图片资源；资源路径转换为包内路径、同步到另一工作区时，只对原本有效且资源身份和阴影配置未变的烘焙迁移签名。SOURCE 中固定保存资源快照；数据中台编辑入口重新打开时更新最新兼容模型并保留实例参数，模型变化会使旧阴影过期；普通快照加载及天空盒后台恢复仍保留原快照。若引用资源无法完整打包，发布在上传前失败并列出需要导入的资源，避免生成内容不完整的工程版本。公开 Viewer DIST 保留当前场景实体、非 CAD 运行组件和点击事件绑定，排除 CAD/DXF 参考图；点击绑定按中台资源 ID 和包内模型路径兼容共享库、工程快照及不同修订，并使用场景已有快照生成部署引用，只有绑定引用的合法模型也会打包。不能完整打包的绑定会在上传前明确报错；编辑器缩略图与公开包中的凭据仍按原有规则清理；已绑定场景会自动使用所属业务项目，不再重复选择；未绑定场景可在发布弹窗选择业务项目，并在首次发布时建立本地绑定；目标业务项目已有当前数字孪生工程时必须显式确认覆盖，并沿用原 `editorProjectId` 创建下一版本；本地基础版本落后时可额外确认强制覆盖，以远端最新版本为基线把本地内容创建为下一版本；发布后的数字孪生 Viewer 在场景就绪后直接消费已持久化的 `modelArrayInstance` 关系，并默认隐藏“场景运行中”状态层、自动巡检浮窗和手动漫游浮窗；自动巡检与手动漫游浮窗只能由大屏组件对应按钮发送的 `startAutoPatrol` / `startManualRoam` 命令打开，打开时互斥切换；同时按下鼠标左键和右键仅切换运行状态层。运行状态层以 1 秒间隔显示 Babylon 实时 FPS，加载、阻断和真实运行异常仍自动显示。
- 大屏全局概览：数据中台普通按钮可发送 `globalOverview` 命令，使发布后的数字孪生 Viewer 取消待启动巡检、停止自动巡检和历史回放、关闭手动漫游与控制浮窗、清除临时选中，并恢复场景发布时保存的初始相机和状态层可见性。
- Electron 启动诊断：开发启动时会输出 renderer 加载、preload 与渲染进程退出日志；React 与 Scene View 初始化异常会显示可读错误页或错误面板，避免窗口内容区静默空白。
- GPU/WebGL 硬件加速：Electron 在 ready 前请求高性能 GPU，并在主窗口明确启用 WebGL；Windows 正式打包版按企业部署策略额外关闭 GPU sandbox。编辑器 Scene View 和发布后的独立 Web Viewer 都使用 `high-performance` 上下文、设置 `failIfMajorPerformanceCaveat=true`，并拒绝 SwiftShader、WARP 等软件 renderer，避免页面静默退回 CPU 模拟渲染；Viewer 无法获得硬件 WebGL 时会显示阻断原因和浏览器 GPU 排查建议。模型文件读取与格式解析仍由 CPU/Worker 执行，几何和纹理上传后由 GPU 完成绘制、Shader、纹理采样与画面合成。
- Unity-like 五面板布局：包含 Hierarchy、Scene、Inspector、Project、Console 五个核心编辑器区域，并支持根据窗口尺寸自动自适应；Toolbar 下方左侧 Hierarchy 与右侧 Inspector 贯通到窗口底部，中间列独立承载 Scene、Project 与 Console；Project/Console 只与 Scene 画布同宽，在约 `1024×640` 及以上窗口中保持五面板可见，Console 默认收纳到 Project 区域最小化入口，点击后以弹窗查看完整日志，Toolbar 与 Project 页签通过内部横向滚动承接溢出，资源卡片按可用宽度自动换行并在超出高度后纵向滚动。
- Babylon Scene View：在 Scene 面板中渲染 Babylon.js 3D 场景，并同步当前场景文档中的基础 Mesh、导入模型与灯光；默认编辑器相机使用更开阔的 `标准` 视野，新场景可视距离为 `12000 m`、最大为 `20000 m`，让地面网格上方和周围保留更大的黑色背景可见范围，并可在 Toolbar 中切换 `近景`、`标准`、`远景`、`全景` 四档可视范围；编辑态、运行预览和发布 Viewer 保留原有右键拖拽旋转、中键拖拽移动、Ctrl+左键拖拽平移、左键短点击单选和滚轮缩放，编辑器额外支持 `Ctrl/Cmd + 左键短点击`逐个加入或移出多选；默认旋转幅度统一为 `0.3°/px`，平移按当前取景高度换算为约 `1` 个画面像素/鼠标像素，滚轮每档缩放当前距离的 `5%`，Inspector 中的缩放/平移/旋转灵敏度随场景保存，发布 Viewer 启动和画布尺寸变化后都会应用同一套值；鼠标滚轮缩放带有最小观察距离与动态近裁剪保护：近景保留 2 cm 观察能力，透视远景按当前距离提高深度精度，避免模型外壳出现条纹、闪烁或缺面；模型表面上的相机操作不会被模型拾取阻断，短点击与拖拽按真实相机输入和位移阈值区分；Toolbar 新增“俯”视角按钮，可保留当前观察中心与缩放距离切换为稳定俯视视角，方便依据地面 CAD 图纸定位并搭建场景。
- 堆垛机聚焦：编辑器、运行预览与发布 Viewer 共用梯笼端面的正向平视近景，观察方向随模型旋转，目标位于下部梯笼中段，距离上限为 8 m；固定轨道不参与机身取景，普通模型、多选及货格聚焦沿用原规则。已有线上场景需重新构建并发布 Viewer 后生效。
- 视口定向罗盘：Scene View 右上角常驻 SVG ViewCube，实时同步世界 X（红）、Y（绿）、Z（蓝）轴方向；支持 Top、Bottom、Front、Back、Left、Right 六个标准面及正负轴端点一键切换，点击后保留当前观察中心与缩放并进入正交硬锁，再次点击当前面恢复进入前的自由轨道方向。罗盘 Home 按钮复用场景“复位视角”，显式“保存当前视角”可持久化六面锁定与投影；运行预览继续显示和允许操作，发布 Viewer 只恢复保存画面但不继承硬锁。
- 大场景原模型 Geometry 无损优化：不降低渲染分辨率、抗锯齿、纹理、材质、光照或几何质量，也不焊接、删面、隐藏可见模型或使用 LOD/代理；同一 `sourceUrl + assetRevision` 的普通静态模型继续复用单份源 `AssetContainer`，每个实体保留独立 Transform、显隐、锁定、拾取和选择语义；基础 Mesh、普通导入模型、复制副本、阵列实例与球形天空盒选中时统一使用深红色（`#8B0000`）约 `5 px` 静态柔和光晕，不再叠加实线主描边，遵循场景深度遮挡且不改写模型表面材质。Scene View 编辑态只会把 `meta.json.dataDriven` 不含自有 `motion` 键的同模板无脚本模型，以及已核对的 Box、Chain、NewChain、GD、HCTS、Shelf、WLTS、YZJ 参数化模型归并为 thinInstance；`motion` 键存在时（包括值为 `null` 或空对象）保持独立渲染，旧快照中的对应 `modelArrayInstance` 关系也会自动解除。合批函数不修改编辑器 Store，保存、数据中台发布和独立部署导出则通过统一序列化入口把幂等 `modelArrayInstance` 关系写入快照。参数脚本先完整执行，随后批次仅复用真实模型的顶点、索引、材质、纹理和所有部件，在任何相机距离与视角都不创建方块、框架或其它替代 Geometry。运行预览和发布 Viewer 直接复用已完成或已持久化的 Geometry 批次、批次 Mesh 和矩阵缓冲，只切换脚本、动画与遥测生命周期，不重新加载、拆批或执行完整场景同步。每个逻辑实体的参数、`assetCode`、Transform、显隐、锁定和遥测绑定均保留。正式批次按空间分片并只对相机视锥外实例执行正常裁剪；实例进入视锥后始终提交原模型 Geometry。设备模型加载最多 4 个并发任务；环境 GLB 使用独立调度器和会话级源容器缓存，不再与设备模型抢同一条队列，同一环境二次打开只克隆工作副本。纯选择变化走 `SceneRuntime.syncSelection()`，Hierarchy 对 10k/50k 行采用固定行高虚拟化。Scene View 内置 1 Hz 性能 HUD，可查看 FPS、CPU/GPU frame time、Draw Call、Mesh、thinInstance、原模型/代理实体数、GPU 顶点/三角工作量与材质分类，并复制最近一分钟报告；代理计数必须恒为 0，监控器可通过 Toolbar 的“性能”复选框显示或隐藏。WebGL 上下文丢失或渲染循环异常会显示可读遮罩，Babylon 恢复后自动清除。详见 `docs/scene-capacity-performance.md`。
- 米制场景单位：编辑器约定 `1 scene unit = 1 m`，Inspector 中 position、位置吸附步长与地面网格均按米解释；普通导入模型的实际 X/Y/Z 尺寸由编辑器运行时原生测量，不依赖参数化脚本。
- 编辑器地面辅助层：Scene View 使用单 Mesh、单 Shader 的相机局部科技蓝地面网格，默认每小格表示 `5 m`，可在 Toolbar 中切换显示/隐藏并选择 `1 m`、`2 m`、`5 m`、`10 m` 四档格子大小；承载平面按主格整数倍跟随当前观察中心，但网格线继续锚定世界米制坐标，不会视觉漂移。细格、主格和粗格按屏幕像素密度自适应显隐，远端平滑渐隐；网格正常接受模型深度遮挡、不写入深度，不再创建第二层网格、GlowLayer 或逐帧呼吸动画。辅助层不参与选中、保存、加载或撤销/重做。
- CAD/DXF 网格参考层：Toolbar 支持导入 `.dxf` CAD 图纸，导入过程中会显示读取、解析和创建参考层进度；`LINE`、`ARC`、`CIRCLE`、`ELLIPSE`、`SPLINE`、`LWPOLYLINE`、`POLYLINE`、`HATCH` 边界、`SOLID/TRACE/3DFACE` 外轮廓与 `LEADER` 会统一换算为米，并按 DXF 正 Y → Babylon 正 Z 的同向规则转为贴近 `y = 0` 网格层的半透明线稿。超过 64 MB 的图纸在 Worker 中完整扫描 BLOCK 与嵌套/阵列 INSERT；每份 BLOCK 图层几何只保存一次，平移、旋转、缩放和镜像以 4×4 矩阵零拷贝回传，并通过 LinesMesh thinInstance 渲染。100 万条折线 / 800 万个点的安全上限只约束唯一原型几何，重复 INSERT 不再展开进坐标数组或被尾部截断；若唯一原型本身超过上限会明确拒绝导入。单位优先读取 `$INSUNITS` 0–24，未声明单位时参考 `$MEASUREMENT`，仍无法判断时明确按毫米兜底；参考图默认锁定、不可拾取，Inspector 会显示源单位、判定来源和换算系数，并随场景保存/加载恢复。
- 创建基础对象：支持创建米制 Cube、Sphere、Plane；基准尺寸分别为 `1 m × 1 m × 1 m`、直径 `1 m`、`2 m × 2 m`，有体积对象拖入 Scene View 时会以底面落地。
- 创建基础灯光：支持创建 Directional（方向光）、Spot（聚光灯）、Point（点光源）、Hemispheric（半球光）、RectArea（矩形面光）五类灯光实体；阴影默认使用静态烘焙模式。在 Inspector 场景属性中点击“更新阴影”，将所有可见实体模型（包括参数、脚本、遥测和动画模型）的当前姿态烘焙到环境接收面；运行时不创建实时阴影生成器。相机移动无需重新烘焙，模型移动或修改参数、环境、太阳方向、阴影浓度后需要更新；发布和导出会阻止缺失或过期结果。地面使用独立静态遮罩并保留原色和平铺纹理，上下重叠楼层自动独立烘焙，不要求人工拆分。阴影按实际投影范围分配像素，目标 128 像素/米，单边上限 8192；分块高质量 PCF 计算避免远处模型扩大深度图范围。每层贴图独立保留精度，同层共享 PNG 引用；总纹理预算为 128M 像素，PNG 数据总预算为 32 MiB。更清晰的烘焙会增加更新时间、材质变体及纹理显存（RGBA 基础层最高 512 MiB，另有 mipmap），运行时每个接收面增加一次普通纹理采样，FPS 需以目标场景和显卡实测。结果随场景保存，原资源不覆盖；运动后的实时阴影和模型之间的动态遮挡仍需实时模式。显式选择实时阴影后，Directional 接管主阴影，没有可见方向光时使用自动太阳；Point/Spot 在实时模式额外生成局部投影，Point 使用六面贴图，开销高于 Spot；Hemispheric/RectArea 不生成投影。方向光在性能/均衡档使用随模型运动刷新的缓存贴图，环境与阴影地面接收投影；高质量档使用实时级联阴影，以阴影距离限定覆盖范围，避免自动深度收紧裁掉最远的平面接收面，普通模型也接收投影，均有额外 CPU/GPU 开销。编辑态中的 Point 使用可拾取球形标记，Directional 使用沿实际照射方向显示的箭头标记，Spot 使用锥形标记，RectArea 使用矩形发光面标记；标记保持近似固定屏幕尺寸、接受正常深度遮挡，并在运行预览和发布 Viewer 中隐藏。
- Hierarchy 选择与分组：Hierarchy 与 Scene View 共用同一多选集合和主选对象；最后加入的实体作为 Inspector 主选，移除主选时回退到最近加入的剩余实体。单文件夹或任意多选都会递归展开所选文件夹、去除重复后代，并在完整选区世界包围盒中心显示仅支持世界坐标移动和旋转的组合 Gizmo；缩放与 Shift 阵列不可用。移动对全部成员应用同一世界位移，旋转以拖拽开始时的组合中心为轴心，同时更新成员位置和自身旋转并保持原缩放；一次拖拽只写入一条撤销记录。隐藏但已就绪的成员继续参与变换，任一成员或祖先锁定时原子阻止整组；任一包围盒或运行时目标尚未就绪时暂不显示 Gizmo，全部加载完成后自动恢复。文件夹自身不保存 Transform，空文件夹不贡献轴心。左侧 Hierarchy 继续提供搜索、全部展开、全部收缩、新建根/子文件夹、单选/多选拖入任意层级文件夹、拖回根层级，以及实体/文件夹级显示隐藏、锁定解锁控制；拖拽会阻止把文件夹放入自身后代。
- Hierarchy 右键菜单：左侧模型树单选或多选后可打开深色上下文菜单，支持场景聚焦、库聚焦、隐藏、复制、粘贴、模型阵列、锁定、重命名、删除、群组和解组；右键未选中对象会切换为单选，右键当前多选对象会保留多选集合。复制文件夹时会递归复制完整文件夹子树，包含空子文件夹和全部普通对象；文件夹副本可粘贴到当前目标文件夹，且粘贴和撤销/重做均按整棵子树处理。删除文件夹仍为非级联操作，其直属内容会提升到原父级。
- Scene View 点击选中：普通左键短点击对象切换为单选，点击空白清空选区；`Ctrl/Cmd + 左键短点击`可逐个加入或移出所有可见、未锁定且可变换的场景实体，点击空白保持当前多选，`Ctrl + 左键拖拽`仍优先平移相机。巡检节点在组合选择中按整条巡检路线处理，重叠对象仍只拾取最前方命中项。
- Inspector 实体编辑：支持编辑选中实体名称、position、rotation、scale 等 Transform 数据；其中 position 按米、rotation 在 UI 中按角度、内部仍按弧度保存。内置 Box 以 1 米基准映射为 `size (m)`；Sphere/Plane 明确显示米制基准尺寸，但通用 scale 仍保持无量纲缩放比例。普通导入模型的 `Model Asset` 区域固定显示只读“实际尺寸 (m)”及 X/Y/Z，加载中或无有效可见几何时显示明确状态。
- Inspector 材质编辑：支持编辑基础 Mesh 的材质颜色。
- Inspector 灯光编辑：支持编辑灯光类型、强度（允许 0）、颜色和夜间行为；Point/Spot 可设置照射范围，Spot 可设置完整光锥角度（界面使用度，保存为弧度）与光束衰减，RectArea 可设置发光面宽高（米），Hemispheric 可设置天空和地面颜色。Point 只显示 position，Directional/Spot/RectArea 显示 position 与 rotation，Hemispheric 将底层 position 字段按实际语义显示为 direction；所有灯光均隐藏无效 scale。新参数支持撤销、保存重开、运行预览和发布 Viewer，旧场景保持原有缺省值。
- Transform Gizmo：Scene View 中支持移动、旋转、缩放三种可视化操控模式，普通拖拽结束后写入撤销/重做历史；Point 灯光只开放移动工具，Directional/Spot/RectArea 开放移动与旋转工具，选择无效工具会自动回退移动，Hemispheric 不显示场景 Gizmo。单文件夹和任意多选临时强制使用世界坐标，只开放移动与旋转，不支持缩放或 Shift 阵列；退出群组选区后恢复进入群组前的工具与局部/世界坐标偏好。编辑模式下选中单个未锁定可阵列实体并使用移动工具时，可按住 `Shift` 拖动 X/Y/Z 单轴箭头进入模型阵列。可阵列实体包括导入模型、内置 Mesh、虚拟定位线框、已解锁 CAD 参考层和特效；文件夹、灯光、全局唯一模型生成器和球形天空盒明确排除阵列，灯光按住 `Shift` 时继续执行普通移动。自动巡检路线只开放移动与旋转，节点子目标同样禁止缩放并关闭 Z 轴滚转；节点拖动只回写对应巡检点位，不改变路线实体 Transform。
- Gizmo 坐标与吸附：支持局部/全局坐标空间切换，并可配置位置、旋转角度、缩放三类基础吸附步长；Shift 阵列沿当前可见局部/世界轴计算方向，阵列手势期间临时忽略位置吸附，普通移动吸附不受影响。
- W/E/R 与批量操作快捷键：在非输入控件聚焦时，可用 W/E/R 快速切换移动、旋转、缩放工具；F 场景聚焦、F11 场景全屏、H 隐藏对象、Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+K 锁定、Ctrl+G 群组、Shift+G 解组、Delete/Backspace 删除当前 Hierarchy 选区；文件夹选区执行 Ctrl+C/Ctrl+V 时会整体复制文件夹及其完整后代子树。
- 撤销/重做：通过命令历史支持基础编辑操作、实体创建、实体删除、实体重命名、材质编辑、灯光编辑、巡检路线/点位编辑与 Gizmo 拖拽的撤销与重做；Hierarchy 批量隐藏、锁定、删除、粘贴、模型阵列、群组、解组以及任意多选/文件夹组合移动与旋转均作为单条命令进入历史，组合变换撤销/重做只恢复全部成员的 Transform，不引入文件夹 Transform 继承。Shift 拖拽阵列确认后同样以一条“模型阵列”命令整体撤销/重做。
- JSON 场景保存/加载：支持将当前场景保存为 JSON 文件，并从 JSON 场景文件加载；保存、文件选择加载和首页最近场景加载成功后都会更新最近场景列表。
 - Project 资源库外观：底部 Project 面板已切换为资源库浏览器样式，位于中间列 Scene 画布下方且与 Scene 同宽，并将图库区域加高到约 `300px` 至 `460px` 自适应，包含模型库、POI库、特效库、主题库、组合库、环境库、天空盒库、图表库、图片库九个页签，以及筛选占位行和可换行资源卡片；模型库卡片使用深色直角卡、上方缩略图、下方两行居中文字和单行省略标题，模型库内置立方体、球体、地面、虚拟定位线框、方向光、聚光灯、点光源、半球光、矩形面光等基础资源，以及环境光 HDRI/IBL 入口；六类光源卡片采用独立照明示意缩略图并说明发光方式和阴影条件；“环境光 HDRI/IBL”卡片打开天空盒库以导入或选择 HDR/EXR，复用全局环境贴图提供照明和反射，不创建重复灯光实体。IBL 不自动投影，当前未接入 IBL Shadows。HDR/EXR 天空盒资源展示在天空盒库，点击天空盒卡片或拖入 Scene 会创建/更新一个进入 Hierarchy 的可见球体并选中，重复放置只更新这个全局唯一实体。图表库会在当前工程绑定数据中台项目后，自动同步该项目绑定的完整大屏卡片，并支持手动重新同步；不解析或展示大屏内部图表，未绑定本地项目不访问数据中台，也不会展示其它项目的大屏；同步仅保存大屏索引元数据，不保存大屏 `jsonContent`，大屏卡片当前仅用于展示，不能点击创建或拖入 Scene View/相机视窗。POI 库保留可点击或拖入 Scene 任意位置的“模型生成器”，重复创建入口会选中已有生成器而不是新建副本；同时新增可创建多条路线的“自动巡检”卡片，点击或拖入 Scene 后进入 Hierarchy；特效库展示新版数字孪生 EFF 和既有组件复用入口，支持点击与拖拽创建，并兼容旧场景中的 EFF；环境库使用独立的单 GLB 文件导入入口，支持点击应用或拖入右侧“环境模型”整条属性行；天空盒库支持导入 HDR/EXR，也可拖入右侧“天空盒资源”区域；所有导入模型进入场景后统一以米为操作单位。
- POI 模型生成器：生成器保存共享生成模板、按顺序匹配的条件规则、MQTT 精确绑定和元数据 TTL；一个场景只有 `entityIds` 中第一个生成器生效，编辑态 Transform 只控制青色可拾取配置标记，不作为任何货物生成点。运行预览中该全局生成器统一管理普通 Conveyor、普通 Stacker 与 `warehouseFlow` 的模板/规则；货物实际位置来自输送面、货叉、locator 或仓储状态机。派生 Mesh/模型不进入 Hierarchy，也不写入场景文件或撤销历史。
- POI 自动巡检：同一场景可创建多条可命名、分类、启停和设为默认的巡检路线，每条路线以实体 Transform 作为局部原点并支持整体移动/旋转、禁止缩放。编辑态选中路线后按 `F1` 或点击“添加点位”记录当前相机的实际位置、观察目标和距离，选中编号节点后按 `F1` 或点击“使用当前视角覆盖”更新该节点；录制保留当前相机高度，`1.7 m` 眼高仅用于第一人称播放；节点不进入 Hierarchy，可在 Inspector 中拖拽排序、复制、删除、聚焦，并编辑世界位置、视角、停留时间、路线速度和相机参数。Scene View 展示红色半透明编号节点、Catmull-Rom 路径、相机视锥及可配置的箱体/球体触发区域，并校验相邻点过近；巡检播放不做场景碰撞或地面可达性检测，相机可直接穿过模型。巡检支持区域进入/离开、距离、到点/停留和手动事件，可组合信息面板、设备高亮、`1920 x 1080` 异步截图、暂停及实时上报响应，包含冷却和单次巡检防重复机制。运行预览和发布 Viewer 共用巡检/历史面板，提供开始、暂停、继续、跳点、停止、紧急停止、`0.5x/1x/2x/4x` 倍速、第一人称/第三人称/轨道观察、手动接管和恢复自动视角；轨迹、事件、截图、异常汇总与任务状态持久化到 IndexedDB，断网时进入 Outbox，支持按时间轴回放、事件跳转及截图同步。路线 JSON 支持导入/导出，`enabled`、默认路线和自动启动相互独立。
- 手动漫游：只有场景中已摆放“手动漫游”POI 时才创建漫游运行时并对外暴露 `startManualRoam`；运行预览和普通独立 Web Viewer 直接显示漫游面板，数字孪生发布 Viewer 初始隐藏该浮窗，仅由大屏组件对应按钮发送的 `startManualRoam` 命令打开；未摆放出生点时保持标准轨道相机。人物漫游控制器支持 WASD/方向键、Q/E/Space、Shift、右键拖拽、双击或按钮进入 Pointer Lock、单指旋转、双指缩放、虚拟摇杆、Gamepad API、第一/第三人称、地面/飞行、独立移动与旋转灵敏度、跟随距离和约 `520 ms` 平滑复位。地面模式包含重力、跳跃、坡度限制、小台阶辅助、第三人称相机避障和可视化碰撞调试。碰撞按网格规模分层：顶点数不超过 `2048` 的廉价 Mesh 保留椭球对三角碰撞；中小型高模改走人物 `24 m` 邻域内最多 `128` 个世界 AABB 代理；厂区环境等可走进内部的超大高模只抽取邻域三角，原 GLB 不开启全场景 `checkCollisions`。模型阵列与其它 thin instance 继续共用同一 AABB 代理池。人物碰撞体通过 `surroundingMeshes` 只扫描邻域廉价网格、AABB 代理、局部三角代理和备用地面，避免 Babylon 默认遍历全部碰撞网格。CAD `LinesMesh` 参考层不参与实体碰撞扫描。人物默认加载 `public/manual-roam/EQ_People.glb`；该资源不含 skin/animation，运行时按材质和连通拓扑生成 GPU Morph Target，使左右手臂和双腿交替摆动，步频按实际水平速度推进（一个完整换步周期对应 `1.6 m` 位移），自定义人物优先播放资源内的 `Idle/Walk/Run/Jump` 动画片段且按同一速度缩放播放倍率。选中手动漫游 POI 后，可在右侧“漫游人物模型”上传自包含 GLB（最大 512 MiB）、选择项目模型或恢复默认人物；每次上传保留独立副本，模型选择支持撤销重做并随场景保存，SOURCE 与 Viewer 部署包包含实际引用的人物资源。人物自动居中、脚底对齐并适配漫游身高；无内置动画的自定义模型保留原始姿态。漫游、自动巡检、外部设备定位和标准视角切换使用互斥相机控制权。
- 内置 EFF 特效：特效库内置报警脉冲光圈、旋转警示灯、定位光柱、雷达扫描圈、火焰、烟雾、火花飞溅、蒸汽泄漏、气体泄漏、水流喷射、管线流动粒子、管线流动箭头、移动双箭头、货物目标定位框、输送方向箭头和疏散路线 16 种实时特效；支持点击或拖拽创建、Hierarchy 管理、Transform、显隐、锁定、复制、阵列、撤销/重做、保存重载和 Inspector 参数实时编辑。
- 模型库筛选：Project 模型库支持按模型名称和模型包 `deviceType` 组合筛选；类型选项来自当前模型资产元数据，内置对象和未声明类型的模型仅在“全部类型”下显示。
- 模型与环境导入：普通模型与环境模型严格分库。模型库点击 `导入模型文件夹`，将有效模型包复制到项目 `Assets/Models`；扫描支持目录本身为单模型包或包含多个一级模型包，并读取 `meta.json`、单位、缩略图和脚本；默认登记 `*.model.ts`，同时登记 `parameterScripts` / `animationScripts` 在 meta 中显式引用的其它 `.ts`（排除 `.d.ts`）。普通模型单位只接受 `meta.json.lengthUnit`：显式合法值按标准系数换算，缺失或空值按 `meter / 1`，显式非法值拒绝导入；参数脚本和几何包围盒都不参与源单位推断。环境库点击 `导入环境 GLB`，单文件保存到 `Assets/Environments/<安全化文件 stem>/<原文件名>.glb`，同名重导采用暂存、备份和失败回滚。打开场景后环境底座与设备模型并行加载；厂区等高模可用 `npm run optimize:environment-glb` 把 PNG 转成 KTX2 后再导入。发布 Viewer 不再阻塞等待环境，设备场景就绪后环境继续后台显现。普通模型、模型生成器输出和环境模型都保留 `lengthUnit + unitScaleToMeters`，运行时只在各自内容根节点应用一次源单位到米的基准缩放；直接导入环境 GLB 默认登记为 `meter / 1`，若源文件实际使用 centimeter / millimeter，可在环境 Inspector 修改“源单位”，运行时会事务式重载并重新居中落地，同包重导继续保留该场景级单位修正。 从其他电脑打开场景后，重新导入同名模型包会按唯一的“包目录名 + 主模型文件名”自动替换旧电脑的绝对资源路径并刷新已有实例。
- 内置天空盒：天空盒库和场景属性选择窗口默认提供“多云天空（轻量）”，HDR 文件为 1,441,554 字节（约 1.44 MB / 1.37 MiB），无需导入即可点击或拖拽使用；资源随编辑器分发，无工程及不同工程均可选择。选用后仍支持旋转、环境强度、分辨率、保存重开、运行预览以及 SOURCE/DIST 打包；发布包仅复制场景实际引用的资源，不重复携带编辑器内置库。原始素材及 CC0 来源见 `public/builtin-skyboxes/LICENSE.md`。
- 天空盒平滑采样：HDR/EXR 全景转换到立方体时使用线性空间双线性插值，修复轻量全景放大后的块状云边，360 度接缝循环取样、上下两极钳制。解码缓存按新算法版本隔离，旧采样缓存会自动重新生成；无需增大天空盒文件或重新导入，已有旋转、强度、分辨率设置保持有效。1K 资源仍有原始细节上限，平滑采样不恢复 4K 细节。

- 天空盒导入与球体实体：天空盒库点击 `导入 HDR/EXR`，把通过扩展名、普通文件、512 MiB 上限、文件头和 RGBE/RLE 完整性校验的资源复制到项目 `Assets/Skyboxes/<安全化文件名>/<原文件名>`。同名资源通过暂存、备份、原子替换和失败回滚更新，不同扩展名可共存；场景只在新纹理加载成功后切换，失败时保留旧效果。天空盒以基础直径 `10000 m` 的双面大球体进入 Hierarchy，默认球心位于 `Y=0` 网格平面，使上、下半球分别处于网格两侧；尺寸倍率限制为 `0.1–1.0`，对应实际直径 `1000–10000 m`，Inspector 使用单一“尺寸倍率”并保持 XYZ 等比缩放，旧非等比数据按三轴最大绝对值迁移。天空盒存在时场景可视距离最低为 `12000 m`，旧场景自动提升；按 F 聚焦时临时使用 `20000 m` 完整取景。相机位于球体内部时背景点击忽略天空盒，位于球体外部时球面可拾取；球体仍支持显隐、锁定，并使用标准 Transform/Gizmo 自行设置位置和 Y 轴水平旋转；HDR/EXR 同时继续作为 PBR 环境照明/反射。Inspector 和场景属性可设置环境强度 `0-5` 与 `256/512/1024` 立方体分辨率。正常编辑流程只维护一个天空盒实体，禁止复制、随文件夹复制和阵列；重新点击天空盒库卡片会更新并恢复显示。旧 `sceneSettings.skybox` 会在加载时自动迁移为球形实体，缺少该字段时保持关闭；跨电脑打开工程时按“包目录名 + 文件名”重关联。数据中台工程包可选迁移 `Assets/Skyboxes`，旧包缺少该目录仍兼容。
- 导入模型资产编号：每个导入模型实例都会生成并保存 `modelAsset.assetCode`，Inspector 的 `Model Asset` 区域可编辑该编号；复制、粘贴会按新实体 ID 重新生成编号。所有阵列副本名称统一按源对象名称递增：末尾有数字时递增并保留前导零，例如 `测试 1001 → 测试 1002`、`DEV009 → DEV010`；只有字符串时直接追加 `1、2、3…`，不添加“副本”。导入模型阵列会创建与阵列数量一致的独立 Scene Entity，并通过 `components.modelArrayInstance.sourceEntityId` 关联共享渲染源；Hierarchy 中可逐个选择、移动、旋转、缩放、显隐、锁定和删除。Babylon 运行时不会逐实体加载或克隆模型，而是按参数组合运行脚本：相同 `parameterValues` 共享一个源或隐藏脚本宿主，不同参数组合分别执行参数化脚本；所有阵列实体仍按该组合的可渲染 Mesh 创建固定数量批次 Mesh，一次提交连续 `Float32Array` thinInstance 矩阵，并通过 `thinInstanceIndex` 映射回具体逻辑实体。旧版 `components.modelArray.items` 场景加载时会自动迁移为独立实体。虚拟定位线框仍把编号写入 `locator.assetId`，内置 Mesh、CAD 和特效继续沿用实体复制语义。场景文件当前使用 `version: 3`，加载器继续兼容 version 1/2，新增天空盒字段为可选字段。
- MQTT 配置入口：Toolbar 提供 MQTT 配置按钮，可在弹窗中填写 MQTT IP/域名、MQTT over WebSocket 地址、topic 与本地模拟参数；只填写 IP 时会自动生成 `ws://<IP>:8083/mqtt`。保存或启用配置只保存场景配置，不会自动连接 broker，也不会自动启动本地模拟。
- MQTT 运行预览：Toolbar 的“运行/停止”是唯一运行入口；点击“运行”并通过预检后才会连接 broker 或启动本地模拟，连接状态 badge 显示 disabled/simulating/connecting/connected/disconnected/error，无效配置会自动打开 MQTT 配置弹窗。运行态允许相机、选择、Hierarchy 搜索/展开、网格、诊断、Console 与场景全屏，只读阻止 Gizmo、Inspector 修改、Hierarchy 变更、资源创建/导入、保存加载、undo/redo 与 MQTT 配置。
- 场景全屏：Toolbar 在运行/停止旁提供全屏按钮，编辑态和运行预览均可使用；点击后隐藏 Hierarchy、Inspector、Project 与 Console，Scene 画布铺满剩余窗口，并请求系统全屏（浏览器拒绝时退化为窗口内最大化）。再次点击或 `Esc`（无弹窗时）退出，`F11` 也会切换场景全屏；桌面端若系统菜单同时占用 `F11`，以 Toolbar 按钮为准。返回首页前会先退出全屏。发布后的 Web Viewer 场景页面不显示全屏按钮；独立打开时仍可按 `F11` 全屏显示自身场景，嵌入数据中台大屏时 `F11` 会请求宿主把完整大屏全屏，避免三维 iframe 遮掉外层组件。
- MQTT 专用设备数据驱动：详见 `docs/mqtt-data-driven-guide.md`，覆盖只读可视化边界、EPV `data[].e/p/v`、JSON Path、多订阅/QoS、`sourceId + deviceType + assetCode` 绑定、按设备类型（stacker/conveyor）分发的专用驱动与模型包 `dataDriven` 声明，以及 stale/fault/conflict 和 Electron `wss://` 安全注意事项。
- 外置参数化脚本：模型包内的 `*.model.ts`、meta 显式引用的 `.ts`，以及数据中台 API 明确返回的 `.ts` 会随模型包复制到项目目录并作为受控 `editor-asset://` 资产授权；导入模型加载完成后，renderer 会以本地可信脚本方式转译并运行同包脚本，兼容 `ParametricModelRuntimeComponent`、`export default class`、`onStart/onUpdate/onStop` 生命周期以及 `babylonjs-editor-tools` 的 `visibleAs*` 装饰器写法。所有长度类参数统一以米输入；脚本在实体根米空间读取未销毁、自身启用、可见且有顶点的有效 Mesh，把米制位移转换回目标父节点局部坐标，并在整机根缩放时保持底部中心锚点。参数脚本只负责模型特有参数化和附加运行逻辑，不负责判断源单位或提供基础米制测量。
- 参数化模型：模型包 `meta.json.modelParameters` 可声明 number、string、color、boolean、enum、vector3、texture 参数，以及绑定到模型节点、网格或材质的安全 JSON DSL；选中带参数配置的导入模型后，Inspector 会以紧凑布局显示“模型参数”区域，参数标签使用自适应宽度并在必要时换行，确保长中文名称完整显示；修改参数会通过场景文档实时驱动 Babylon 模型外观变化，并支持随场景保存/加载与撤销/重做。参数变化完成后，编辑器会重新测量实际尺寸；没有参数脚本的模型仍正常显示米制尺寸。
- 模型库拖拽放置：模型库中已导入的真实模型卡片可直接拖拽到 Scene View，释放鼠标时会按当前鼠标射线与 `y = 0` 地面平面的交点创建模型实体；点击模型卡片仍保留原点快捷导入行为。
- Assets 目录能力：模型库已接入本地模型文件夹扫描和 glTF/GLB 导入，环境库已接入单 GLB 导入，天空盒库已接入 HDR/EXR 导入；三类资源分别保存到 `Assets/Models`、`Assets/Environments` 和 `Assets/Skyboxes`。其它资源类型的真实分类、搜索、扫描与导入会在后续资源库功能中继续补齐。

数字孪生发布扫描到不属于当前项目或共享资源缓存的资源时，仅记录警告并跳过该资源的 SOURCE 复制，继续发布；同一资源包的重复引用只提示一次。SOURCE 中仍保留场景，重新打开时可能需要重新导入被跳过的资源。Viewer DIST 仍按现有文件授权和完整性规则处理实际使用的资源。

数字孪生源工程发布会按完整资源包的文件清单和 SHA-256 处理同名副本：内容一致时合并打包，模型、脚本或元数据不同则分配独立目录并统一改写场景引用。重新打开这类工程时，模型保留工程包内的固定版本，后台同步不会自动覆盖；用户显式更新模型资源时，模型及脚本等关联信息整体更新，并解除固定。发布过程中 SOURCE 与 Viewer DIST 使用同一份文件校验清单，资源在复制期间发生变化时会明确失败，避免形成混合版本。旧场景无固定标记时维持原同步行为，切换工作区不会自动迁移或删除旧目录。开发回归入口：`npm run test:source-resource-plan`。

从首页“数据中台项目”或数据中台深链打开工程时，以服务器当前 SOURCE 为准：每次重新查询版本并下载，不因本地绑定版本号相同就复用可编辑文件。与远端不同的本地场景和资源会先备份到工作区 `Conflicts/<项目ID>/`，再事务替换当前项目的 `Scenes`、`Assets` 和资源索引；内容相同不重复备份。远端无工程包时打开空项目，远端请求失败或包无效时明确失败，不回退到本地内容。继续编辑本地未发布内容应使用本地项目或最近场景入口；查询阶段同样支持取消。
