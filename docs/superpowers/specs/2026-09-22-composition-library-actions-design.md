# 组合模型保存入口调整

## 目标与范围

面向在数字孪生编辑器中摆放、复用组合的用户，将保存操作与下方组合库放在一起，消除画布左上角独立按钮的突兀感。沿用现有深灰面板、青色强调色、28px 工具栏按钮和 13px 字号，不新增依赖，不调整组合数据及同步协议。

## 交互设计

- 组合库搜索栏右侧设置唯一的“保存组合”入口，带组合图标及拖拽手柄。点击打开命名表单；拖到空白区新建；拖到已有卡片替换。
- 组合库工具栏同时容纳同步、导入次级操作。下方保留简短操作提示与状态消息；卡片单行横向滚动，操作区完整可见。
- 未选对象、只读及处理中禁用保存；完整成员合法性继续由现有保存校验处理。替换仍保留卡片及中台资源 ID。
- 进入组合内部编辑时，场景标题栏显示组合名称和“完成编辑”，保留 Esc 退出，画布不放保存悬浮按钮。
- 较窄面板收起次级按钮文字，保留图标、提示与可访问名称；搜索、保存及卡片操作保持可达。

## 验收

检查实际浏览器中的正常、未选择、处理中和内部编辑状态；验证按钮点击、真实拖拽新建与替换、再次拖入、保存重开及 Esc。检查宽窄视口下按钮位于组合库、编辑状态位于标题栏、卡片底部未被裁切，完成类型检查与代码审查。

## 边界

使用本地 WebGL 场景及临时组合包验证本次界面变更，不代表已安装桌面程序或真实中台环境验收。

## 设计验收记录（2026-09-22）

结论：通过本地界面验收。

- 位置与样式：保存入口位于组合库搜索栏右侧，使用现有青色强调色，画布无保存悬浮按钮；内部编辑状态及退出按钮位于 Scene 标题栏。
- 布局：1600 × 1050 和 1100 × 800 浏览器视口均通过边界检查；次级操作在窄面板收起为图标，卡片导出和恢复操作完整可见。
- 交互：16 项浏览器检查通过，包括空选禁用、键盘打开与取消、真实拖拽创建、同一卡片替换、内部成员调整、再次拖入、独立实例、显式升级与撤销重做、保存重开。
- Esc：切换资源库后仍能退出内部编辑；命名表单内按 Esc 只关闭表单，并恢复保存按钮焦点。
- 验证命令：`npm run typecheck`、`node scripts/smoke-editable-composition.mjs` 均通过，浏览器无 pageerror。
- 代码审查：已复核选区读取、只读及处理中禁用、场景会话检查、拖拽数据协议与键盘事件清理；未发现本次变更的阻断问题。
- 测试环境：组合包写入临时目录，资源准备和同步接口使用本地夹具；Vite 使用独立缓存和可用端口，结束后释放测试浏览器与服务。未验收真实中台、已安装桌面程序或完整屏幕阅读器操作。

效果截图位于 `output/playwright/editable-composition/`：`composition-toolbar-wide.png`、`composition-toolbar-narrow.png`、`composition-editing.png`；检查结果为同目录的 `result.json`。
