# 自动巡检期间模型点击高亮设计

**日期：** 2026-08-10

## 目标

在数字孪生编辑器运行预览和发布 Viewer 中，允许用户在自动巡检播放期间点击真实业务模型并使用现有选择描边高亮，同时不暂停或改变巡检相机时间轴。

## 交互规则

- 编辑器运行预览与发布 Viewer 都支持鼠标左键短按和单指轻触选择。
- Viewer 场景就绪后始终可选择，不受巡检 `idle`、`moving`、`dwelling`、`paused`、`returning`、`completed` 阶段限制。
- 指针拖拽、触摸滑动、滚轮或键盘相机操作仍属于手动相机接管；普通点击不暂停巡检。
- 点击判定只依据真实指针移动距离，不使用巡检产生的相机位姿变化；拾取采用释放时坐标。
- 普通点击为单选，点击其他模型转移高亮，点击空白清除，重复点击保持；编辑器保留 Ctrl/Cmd 多选。
- 编辑器运行预览同步 `selectedEntityId`、Hierarchy 与 Inspector，但保持只读且不启用 Transform Gizmo。
- Viewer 本地高亮不自动过期，与外部 `focusAsset` 临时高亮独立叠加；不新增上行消息或协议字段。

## 可选择对象

- 支持导入模型、内置几何、参数化模型、模型阵列逻辑实体和 thinInstance。
- 运行态允许选择 locked 模型，但 locked 仍不可编辑。
- 隐藏实体不可选择。
- 巡检路线/节点、灯光、相机、天空盒、地面网格、文件夹及其他编辑辅助对象不可选择。
- 最近的真实可见模型优先；不增加穿透循环选择。

## 视觉与非目标

- 统一复用 `SceneRuntime` 的 `SelectionOutlineLayer`，不改材质、不新增巡检颜色。
- 点击不自动聚焦相机，不打开 Tooltip、详情或菜单，不触发数据查询。
- 不增加 Hover 高亮，不改变自动巡检播放控制器和外部交互协议。

## 架构

1. 提取共享的 Pointer 点击会话判定，只根据指针轨迹区分点击与拖拽。
2. `SceneRuntime` 增加运行态模型拾取策略，允许 locked 业务模型但过滤隐藏和辅助实体。
3. `SceneRuntime` 增加 Viewer 本地高亮来源，并与编辑器选区、外部临时高亮做并集合成。
4. 编辑器运行预览使用运行态模型拾取；普通编辑模式保持现有巡检节点及可编辑实体拾取逻辑。
5. 发布 Viewer 绑定 Pointer 选择生命周期，并在场景释放时清理监听与本地高亮。

## 验收

- 巡检相机持续移动时，静止短按模型可以成功描边，播放阶段不变。
- 拖拽相机不产生选择；点击空白清除选择。
- locked 模型可在运行态选中，隐藏模型和辅助对象不可选。
- thinInstance 只高亮命中的逻辑实体。
- Viewer 本地高亮与外部 `focusAsset` 高亮可以同时显示，外部高亮清除后本地选择仍保留。
