# 环境场景底座显示设计

## 目标

环境模型用于厂房主体或周边地理环境，只作为一个全局静态视觉底座。它不进入 Hierarchy，不承担普通实体的选择、碰撞、脚本或动画职责，并在编辑器、运行预览和导出 Viewer 中保持一致。

## 数据契约

`sceneSettings.environment` 持久化：

- 资源包路径、显示名称、可选文件大小、缩略图与变体；
- `lengthUnit + unitScaleToMeters`；
- `placementMode: scene-base | legacy-left`；
- 米制 position、弧度 XYZ rotation、统一 scale；
- `visible` 与 `opacity`。

场景文件版本保持 `3`。旧场景缺少新增字段时补齐安全默认值并标记为 `legacy-left`，不改变原有位置。

## 摆放规则

- 新环境首次应用或执行“重置摆放”时，以应用源单位缩放后的包围盒计算：X/Z 中心对齐世界原点，包围盒最小 Y 对齐 `Y=0`。
- 旧环境继续把右边界放在 `X=-2m`、底部放在 `Y=0`、Z 中心对齐原点。
- 旧环境只有在用户点击“转换为场景底座”后才切换新规则。
- GLB 缺少可靠单位信息时默认 `meter / 1`；Inspector 可改为 centimeter 或 millimeter，修改后事务式重载、重新居中，并在同包重导时保留修正。

## 运行时边界

`SceneEnvironmentRuntime` 独立封装环境生命周期：

1. 通过 SceneRuntime 的四路共享加载调度器读取候选 `AssetContainer`；
2. 排除容器中的相机、灯光和动画组，停止动画；
3. 将顶层模型节点挂到独立内容根并应用源单位缩放；
4. 禁止所有环境 Mesh 拾取；
5. 候选完成摆放、材质、统计和包围盒计算后才替换当前环境；
6. 候选失败或被后续请求取消时释放候选并保留当前环境。

静态状态冻结节点世界矩阵和材质；进入临时调整模式时解冻，结束后重新冻结。不创建环境专属阴影、LOD、代理、碰撞或地形吸附。

## 显示与交互

Inspector 提供：

- 加载状态、显示名称、世界尺寸、源单位、文件大小；
- position、XYZ rotation、统一 scale；
- 显隐、透明度、正常/半透明/隐藏快捷状态；
- 聚焦、重置摆放、清除、旧版转换；
- 临时场景 Gizmo 与 Esc/完成退出；
- Mesh、Primitive、顶点、三角形、材质和纹理折叠统计。

半透明状态把原材质 alpha 与环境 opacity 相乘，强制 Alpha Blend 并关闭深度写入，优先保证设备模型在厂房底座上清晰可见。

环境 Gizmo 不支持 Shift 阵列；缩放工具只显示统一缩放手柄。每次完整拖动提交一条 Undo/Redo 记录。点击普通实体、按 Esc、点击“完成调整”、隐藏环境或进入运行预览都会退出调整模式。

## 相机与 Viewer

环境聚焦按包围球计算完整取景距离，必要时临时提高可视距离但不超过 20 km。移动 ArcRotateCamera target 时保存并恢复 alpha/beta，避免高差较大的环境把相机翻到地面下方。

导出 Viewer 使用同一环境运行时，并在环境加载成功后才进入 ready。环境加载失败时显示阻断错误，不静默忽略。

## 验证

- 数据测试覆盖旧字段迁移、新字段往返、资源刷新保留配置、两种摆放算法和单位修正保留；
- NullEngine 测试覆盖自动居中落地、候选失败保留旧环境、同源显示更新、幽灵深度写入和旧版偏移稳定；
- Electron 人工验证覆盖实际厂区 GLB、源单位修正、聚焦、透明/隐藏、Transform/Undo、统一缩放 Gizmo、Esc 退出和统计面板。
