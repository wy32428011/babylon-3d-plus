# 数字孪生特效详细配置与数据绑定

本文对应当前编辑器及同版本 Viewer 的 V2 特效配置。按当前特效库登记表统计，**46 种可见独立特效都有专用参数，共 330 个按类型登记的参数项**；这里的 330 是各类效果参数项累计数量，包含不同类型中名称相同的参数，不是单个效果需要填写的数量。统一目标绑定、数据绑定和运行诊断在这些专用参数之外提供。

图标/图表立标、报警管理器保持原有组件配置与运行方式。特效库中的“报警脉冲光圈”“旋转警示灯”是独立视觉组件，属于本次详细配置范围，不替代报警管理器的业务规则。

## 1. 入口与兼容行为

1. 从“特效库”添加效果，选中场景中的特效实体。
2. 在属性中点击 **“启用详细配置与数据绑定”**。
3. 根据当前类型配置“目标与锚点”、专用参数和“数据绑定”。不需要业务数据时选择“静态配置”。
4. 在运行预览中查看“运行诊断”；数据绑定可先使用“测试取数”检查当前草稿。

旧场景中没有 `configuration` 的特效不会在加载或保存时自动升级。建筑、区域、路径等效果未显式设置的新参数继续回退到原有通用配置；只启用目标或数据绑定不会强制填满专用参数默认值。部分旧版可见效果启用详细配置后使用对应的新参数实现，面板会提示这一行为，可通过撤销恢复。

“取消详细配置”移除该特效的 V2 目标、数据和专用参数配置，恢复按原有静态属性运行；它不是临时暂停按钮。要临时停用请使用特效本身的启用开关。

数字和文本专用参数在失去焦点或按 Enter 后提交。颜色、下拉和开关按面板操作提交。复杂行配置采用 **JSON 数组编辑**，需点击对应的“应用…”按钮；未应用的 JSON 文本不会进入场景保存。

## 2. 目标来源与设备身份

| 目标来源 | 含义与适用方式 |
| --- | --- |
| 特效自身坐标 | 通过特效实体的 Transform 摆放，适用于不依附设备的区域、路径、粒子等效果。必须绑定模型的效果不提供这一选项。 |
| 场景对象 | 勾选一个或多个已有模型/网格，也可加入层级面板已选模型，按场景实体 ID 关联；目标跟随保留单目标选择。 |
| 模型类型（模型库模板） | 将普通模型资源拖入“特效模型模板拖放区”。所有可绑定模型的特效均可匹配场景已有实例和运行时生成实例；非镜头特效默认绑定全部同类型模型。 |
| 设备身份匹配 | 按数据源、协议设备类型和资产编号筛选已有设备模型。 |
| 环境模型 | 供轮廓、棱线、自发光、扫光、渐变、全息、X-Ray 和溶解生长这 8 类建筑外观效果使用。 |

**类型绑定不要求编辑场景已经存在对应模型。**实例由现有模型生成器、批量模型生成路径或已有场景模型提供，跟随组件本身不创建设备。资源匹配使用中台稳定资源身份或经资源搬迁映射的本地资源引用，不根据可能重复的显示名称猜测。同一名称的两个不同资源不视为同一种模板。

完整设备身份为：

```text
sourceId + deviceType + assetCode
例如：factory-a + rgv + "000317"
```

- `sourceId` 是场景 MQTT 数据来源标识。模型没有显式指定来源时，现有设备绑定可能使用 `default`。
- `deviceType` 是协议设备类型，不应直接用模型库分类名称代替；应核对模型的遥测或数据驱动配置。
- `assetCode` 始终作为字符串保存和传输。`"000317"` 与 `"317"` 是不同编号。
- 设备身份筛选可以保留“不限定”数据源，但不同来源出现相同编号时，应明确选择来源以消除歧义。

“唯一对象”命中多台设备时会提示进一步限定，不会选择列表中的第一台。候选对象按钮可以补入完整设备身份；没有设备身份的候选可改为直接场景对象绑定。“全部同类型 / 匹配模型”按配置的目标数量上限运行，最多 64 个；超过上限会提示配置问题。**目标跟随每次锁定一个实例；轨迹拖尾可以绑定多个目标，每个目标分别记录自身轨迹。**

找不到目标时，运行时等待匹配对象或模型加载，不创建替代模型。目标跟随不会因为未匹配到设备而把相机移到原点。

### 多个指定模型与全部同类型模型

两种绑定方式可以按实际需要选择：

- **多个指定模型**：目标来源选“场景对象”，逐个勾选模型，或先在层级面板多选再点击“加入层级已选模型”。同一模型去重处理，不会重复叠加；“已绑定对象”中可单独移除或清空。对象被删除后引用仍显示为缺失，便于明确移除，不能静默改绑到其他模型。
- **全部同类型模型**：目标来源选“模型类型”，从模型库拖入资源，匹配方式默认“全部同类型 / 匹配模型”。可进一步限定实例来源、生成器、数据源与编号。之后新增或生成的同类型实例自动纳入，销毁的实例清理自身特效，其他目标继续运行。

同一个特效共享一份专用配置，运行时为每个目标保留独立的锚点、动画、数据触发与历史轨迹。修改这份配置同时更新所有绑定目标；需要不同表现时可使用不同特效组件。多选数量受“目标数量上限”限制，最多 64 个；降低上限前需要先移除超出的显式对象，不会截断已选列表。

运行诊断先汇总全部目标状态，再在“逐目标状态”中分别显示每个模型的取数、映射、缺失、加载与材质支持情况，不将最后一台设备的数据冒充为整个组件的数据。

共享库存薄实例可以绑定光圈、粒子、路径等空间挂载特效，以及相机跟随；单个薄实例不能独立修改共享材质，因此建筑外观、剖切等模型表面效果会对该目标显示不支持，而不会误修改整批库存模型。普通场景模型和生成器独立模型不受这项限制。

相机目标跟随仍在同一时间跟随一个实际实例；模型类型筛选可覆盖多个候选，再由唯一匹配或运行选择确定当前目标。环境雾与昼夜属于全局场景效果，不显示模型目标多选。

### 环境模型与部件锚点

环境模型仍可从“场景属性 → 环境属性 → 建筑物特效”添加，也可在建筑外观特效中选择环境目标。调参不重新加载环境 GLB；原模型必须实际包含需要显示的结构。

设备绑定可以选择模型原点、包围盒中心或指定部件，并设置“目标局部偏移”。指定部件支持名称/ID或相对根节点路径；重名部件需要使用完整路径，无法唯一定位时会提示问题。模型表面效果还可以用“作用部件路径”限定网格，用发光材质名称限定自发光材质。当前文本输入可用分号分隔多个路径/名称；JSON 或场景配置中的换行形式也可识别。

包围盒中心适合模型原点位于地面或偏离几何中心的设备。局部偏移随目标的变换解释；跟随效果另有“视点局部偏移”和“自定义相机局部偏移”，分别控制观察点和相机摆放。

## 3. 按模型类型跟随运行时生成实例

1. 添加“目标跟随”，启用详细配置，目标来源选择“模型类型（模型库模板）”。
2. 从模型库拖入需要跟随的类型。编辑场景没有同类实例时显示等待生成，可以直接保存。
3. “实例来源”选择全部、编辑场景模型或运行时生成模型；运行时生成范围可进一步限定某个生成器。
4. 选择实例编号类型。设备使用资产编号，货物使用容器编号；需要按承载者定位货物时选择承载设备资产编号。编号始终精确保留前导零。
5. 按需要限定数据源、协议类型和编号。例如设备身份为 factory-a / rgv / "000317"。类型与编号是两层条件，不将模型显示名称当作协议设备类型。
6. “实例定位方式”选择唯一匹配时自动跟随，或运行时手动选择。编号可以留空；同类型多实例时不会任取第一项。
7. 设置锚点、视角、前向轴、距离、高度、平滑与限速。例如水平距离 10 米、高度 5 米、平滑时间 0.3 秒、最大追赶速度 8 米/秒；最大速度为 0 时不限制。
8. 进入运行预览。场景左上方“目标跟随”面板显示等待、加载、当前实例及可选候选；生成模型就绪后再开始跟随。Viewer 提供相同面板。

实例选项显示场景/运行时来源、业务编号和加载状态。加载中、隐藏或加载失败的候选不能手动选中。运行目标的选择只保存在本次会话，预览锁定时也可以操作，不改写场景、撤销历史或自动保存。

“唯一匹配时自动跟随”在首次只有一个候选时自动锁定；新增同类型对象不会令已锁定镜头换目标。“运行时手动选择”等待从运行面板选定。点击“清除本次选择”恢复配置策略：唯一匹配策略仍可重新自动锁定，手动策略继续等待选择。

具有稳定业务身份的目标销毁后，会等待同一身份重新出现；未就绪时保持镜头，不跳向原点。没有稳定身份时重新按唯一匹配或手动选择策略定位。生成器切换成其他模型类型后，仍绑定原类型的跟随组件继续等待原类型。

跟随读取模型的最终世界位置和朝向，包括生成器输出与批量薄实例。模型运动仍由现有运动驱动负责；跟随不增加第二套位置写入逻辑，也不把薄实例批次全部拆成独立节点。

### 数据身份与货物身份

模型类型、目标实例编号和取数设备身份分别配置。容器编号属于货物身份，不能当作设备资产编号发起遥测查询。“继承数据身份”可选择目标自身设备或承载目标的设备；承载者来自运行时生成关系，不能从容器编号猜测。

完整填写目标数据源、协议设备类型和设备资产编号后，“测试取数”可以先于模型生成执行。相机仍等待实际模型就绪。货物尚未生成、承载设备身份尚未明确时，可使用独立 MQTT 或 HTTP 显式填写设备身份测试。

开启“允许鼠标接管并暂停”后，人工调整镜头会暂停自动跟随；在运行面板或属性运行诊断中点击“恢复跟随”可重新接管。实例重建、数据恢复不会自动解除人工暂停。多个镜头效果、巡检或漫游发生控制权竞争时仍遵守现有占用规则。停止预览或切换场景会清理运行选择、目标目录和节点引用。

## 4. 四种数据来源

| 数据来源 | 配置与行为 |
| --- | --- |
| 静态配置 | 使用手工专用参数，不发起取数。适合装饰、固定区域、人工剖切等。 |
| 继承目标模型 MQTT | 使用目标实际设备身份读取快照；类型绑定还可明确选择承载设备身份。完整配置的设备三元组可在实例出现前测试，容器编号不能替代设备号。多目标效果在运行时逐个继承各自身份；手动“测试取数”可选择一个已有场景模型作为样例，不更改实际绑定范围。 |
| 独立 MQTT 设备 | 明确填写 MQTT 数据源、协议类型和资产编号；特效数据设备可以与挂载模型不同；这里显式绑定的同一设备数据会共享应用到全部目标。 |
| 中台托管 HTTP | 选择已注册 HTTP JSON 数据源，或查询中台设备最新遥测。地址和认证来自应用/项目运行配置，特效配置中不接受任意 URL、请求头和凭据。 |

MQTT 两种方式都复用已有连接和设备快照，不为每个效果新建连接。“测试取数”不会主动连接 Broker；应确保现有运行预览或设备数据链路已经收到该设备的数据。

### 中台 HTTP 的两种取数方式

**已注册 HTTP JSON 数据源**填写数据源管理中的正整数字符串 ID，例如 `"42"`。运行时调用：

```text
POST api/v1/data-sources/fetch
{ "id": "42", "runParams": { "assetCode": "000317" } }
```

数据源应在中台配置为可用的 HTTP JSON 数据源，并按需要使用运行参数 `assetCode`。设备厂家、型号、业务状态等信息是否存在，取决于该数据源实际返回内容。本实现传递的运行参数为 `assetCode`，不提供任意请求正文编辑器。区域统计等非单设备数据源可不填写资产编号。

**中台设备最新遥测**需要单独填写存储空间 `namespace`，并提供协议设备类型和资产编号；后两者留空时可继承唯一目标的身份。运行时调用：

```text
POST api/v1/dataflow/mqtt-storage/detail
{ "namespace": "factory-storage", "deviceType": "rgv", "deviceNo": "000317" }
```

`namespace` 不等于 MQTT `sourceId`，不会自动从来源标识推导。这里将资产编号作为请求中的 `deviceNo`，所以中台设备编号需与该字符串一致；不一致时应填写实际用于查询的资产编号。最新遥测接口提供最新设备数据，不保证包含完整设备台账或历史记录。

HTTP 正常轮询由运行中的可见、启用效果推动；编辑属性不会自动轮询。相同请求身份共用结果，默认最多 128 个共享请求条目、4 个并发请求；失去引用或运行时销毁会取消请求。单次响应上限为 2 MB。UI 的轮询间隔范围为 500～3600000 ms，请求超时范围为 500～30000 ms。

多个效果共享同一请求时，使用当前活跃效果中最短的轮询间隔和超时；较快的效果停用后，剩余效果可以恢复较慢的节奏。在途请求保留启动时的超时设置，后续请求使用更新后的配置。

## 5. 字段映射、单位与触发

“数据绑定”整组属性先作为草稿编辑，再点击 **“应用数据配置”** 保存。**“测试取数”测试当前草稿，不保存修改**；测试结束会停止测试请求，可中途点击“停止测试”。切换目标、类型或数据配置时旧测试会取消。

字段支持点分路径和数字下标，例如 `speed`、`data.temperature`、`data.items[0].value`，不执行表达式。托管 HTTP 字段路径从 `responseBody` 解析后的业务 JSON 开始，不需要手动穿透中台传输包装；最新遥测和 MQTT 同时支持适配后的字段，以及可用的原始解析数据路径。先看测试返回的字段样例，再决定路径。

每条映射选择一个当前效果支持的目标属性，包括公共颜色、强度、速度、启用状态、适用的通用数值，以及登记为可绑定的专用参数。并非每个结构字段都开放高频绑定。数值换算为：

```text
特效数值 = 来源数值 × 倍率 + 偏移
毫米转米：倍率 0.001
0～100 的百分比转 0～1：倍率 0.01
```

可绑定向量参数接收仅含有限 `x`、`y`、`z` 的对象，倍率和偏移应用于三个分量。颜色使用 `#RRGGBB`。缺失、空值、无法转换、越界及合法的数值 0 分开处理，错误不会静默变成 0。

枚举配置使用 JSON 数组，例如将运行状态映射为启用开关：

```json
[
  { "value": "running", "output": true },
  { "value": "stopped", "output": false }
]
```

配置了枚举时按来源值的字符串形式精确匹配，不再进行倍率/偏移换算。枚举有未应用草稿时，需要先应用枚举，再测试或保存整组数据配置。每个效果最多 64 条字段映射，每条映射最多 32 个枚举值。

溶解生长、逐段点亮、楼层展开、零件爆炸及剖切映射到进度时，运行副本切换为外部进度驱动，不再让内部播放时钟争抢业务进度。溶解的完成比例达到 1 后完整显示原模型；循环、生长方向、边缘与噪声等仍由专用参数控制。

“条件触发”支持等于、不等于、大于、大于或等于、小于、小于或等于，并可设置 0～60000 ms 去抖。条件未满足时不启用效果；字段缺失或数据无效时不能作为满足条件处理。

### 数据时效与失联

“预期更新间隔”表示期望节奏，不会改变设备采集或 MQTT 发送频率。实际过期判定使用“数据过期时长”（TTL）；运行时检查接收时间，以及可用的消息源时间戳/中台最后成功时间，反复读取旧消息不会自动变成新数据。

| 缺失 / 过期行为 | 运行结果 |
| --- | --- |
| 暂停效果 | 有历史有效结果时保持该结果并暂停动画时间/锚点更新。 |
| 隐藏效果 | 缺失或过期时停用效果，恢复有效数据后重新投影。 |
| 保持最后有效值 | 有历史有效结果时继续使用该结果。 |

从未取得有效数据时，不会凭空产生“最后有效值”。字段映射错误也进入异常处理并在诊断中显示。启用了条件触发后，数据失效时触发条件会等待有效数据，“保持最后有效值”不会绕过该校验。切换数据设备身份会清除旧设备的运行缓存，避免暂时沿用另一台设备的值。

## 6. 热力图、区域分级和三维数据柱的数据集

这三类效果提供“空间数据集”：填写记录数组路径、稳定记录 ID、坐标、数值和标签字段。根数组使用 `$`；对象中的数组可使用 `rows` 或 `data.rows`。最多处理 64 条记录，超限、重复 ID、无效坐标和缺失数值会提示。

例如，托管数据源返回的业务 JSON 为：

```json
{
  "rows": [
    { "id": "A", "name": "仓储区", "x": 12000, "y": 0, "z": 5000, "value": 38 },
    { "id": "B", "name": "包装区", "x": 18000, "y": 0, "z": 7000, "value": 52 }
  ]
}
```

可配置数组路径 `rows`，记录 ID `id`，坐标 `x/y/z`，数值 `value`，标签 `name`，坐标换算倍率 `0.001`。换算后单位为米；点位数据需要有效的 X、Y、Z，二维数据也应提供数值为 0 的 Y。

坐标空间选择“相对特效的局部坐标”或“场景世界坐标”。世界坐标在运行时按特效变换换算到局部，避免特效本身平移后重复偏移。记录按稳定 ID 对齐，接口数组顺序变化不会把数值套到另一处位置。

**已经绘制了区域多边形时，区域分级按区域 ID 更新指标**，保留场景中的区域轮廓，不要求每条指标再返回坐标；可选标签可更新区域名称。数据中出现没有对应多边形的 ID 会提示，已有区域缺少本次记录时保留其配置值。热力图与数据柱按完整的点位记录生成显示。

数值色带、等级阈值、自动/固定数值范围、热区影响半径、柱高换算和单位标签在对应专用属性中配置。场景绘制区域与接口数值需使用相同的稳定 ID。

## 7. 场景绘制路径和轮廓

以下效果支持“场景绘制”：流光路径、流动箭头、飞线、轨迹拖尾、路径逐段点亮、管道流动、疏散路线、区域边界流光、区域填充、水面、光墙围栏和区域分级。

1. 选中特效，区域分级先填写或选择“绘制区域 ID”。
2. 点击“场景绘制”，在场景地面上按顺序左键添加点。
3. 观察临时青色点线；需要修改时点击“撤销绘制点”。
4. 点击“应用绘制”一次提交，或点击“取消”/按 Esc 丢弃草稿。

路径至少 2 点，闭合路径及区域至少 3 点，最多 128 点；拒绝重复、折返重叠和自交。轮廓自动闭合，不需要重复点击首点。点位通过实际特效根节点的世界矩阵换算为局部坐标，兼容旋转和非均匀缩放；不使用屏幕坐标直接保存。

光墙只存局部 X/Z 轮廓，显示沿用已有底部标高、高度和透明度。区域及水面轮廓按局部 X/Z 投影检查，不适合退化为一条线的垂直投影。水面绘制后自动启用多边形水域。区域分级只替换指定 ID 的轮廓，并保留该区域数值。飞线取首尾点作为起终点，弧高由专用属性控制。绑定了运动目标的拖尾按实际位置采样，手绘路径主要用于未绑定时的演示。

绘制期间左键由绘制工具接管，不切换场景选中对象；右键/滚轮仍可用于调整视角。切换选中对象、切换场景或进入运行预览时自动取消草稿。临时点线不进入保存数据；应用整个草稿只产生一次配置提交，可一次撤销。

```json
[
  { "nodePath": "Building/Floor1", "order": 0, "fixed": true },
  { "nodePath": "Building/Floor2", "order": 1, "distance": 4, "axis": "y" }
]
```

结构组也可使用 `offset: {"x": 0, "y": 4, "z": 0}` 指定世界米偏移。父子组避免重复位移；固定父组不会再被其子组间接展开。渐变断点示例：

```json
[
  { "position": 0, "color": "#0088ff" },
  { "position": 0.5, "color": "#00dd99" },
  { "position": 1, "color": "#ff4400" }
]
```

高度渐变最多 8 个断点。结构效果依赖模型真实部件：单一整体网格不能自动拆成楼层或零件；X-Ray、剖切、屋顶淡出不能生成原模型中不存在的内部结构；剖切不自动生成封口。指定节点不存在或同名冲突时应修正路径。相同模型上的表面效果保留现有占用顺序和报警优先规则；固定场景主题仍优先于昼夜效果，显式雾关闭后恢复主题/场景雾。

## 9. 保存、复制与发布

详细配置与特效实体一起保存，支持撤销/重做及保存重开。复制实体时，场景内单目标和多目标引用随同时复制的模型逐项重映射；只复制特效时保留原目标引用。业务数据源、协议类型和字符串资产编号不因复制自动改号。复制出多台具有同一业务身份的设备后，唯一目标匹配可能变为歧义，应重新明确设备身份。

**实时数据只生成运行副本**，不把遥测值、临时轨迹、测试结果、诊断缓存或绘制草稿写回编辑场景或撤销历史。持续收到数据不会产生自动保存修改。

| 产物 | 配置与模板引用处理 |
| --- | --- |
| 编辑器场景 / SOURCE | 保留 V2 配置和模型模板编辑信息，包括用于资源关联的原始路径/URL及资源身份/场景引用证据。 |
| DIST / Viewer | 保留目标、数据和专用参数；类型引用使用中台稳定身份或与生成器模板一致的部署资源映射，剥离本机路径。仅有生成器模板、没有编辑态实例时也能保持类型绑定。类型引用不作为独立模型加载，也不重复打包。 |

使用此功能的已发布项目需重新构建并发布匹配版本的 Viewer。Viewer 的 HTTP 地址来自项目运行配置，缺省使用当前站点来源；中台认证、同源/CORS与业务访问权限仍需由部署环境满足。不能仅凭本地配置测试认定线上 Broker、业务接口或部署已经可用。

跟随组件不会根据业务接口自行创建模型；已有生成器仍负责实例生成。本配置不增加历史轨迹回放、完整设备台账自动发现或任意脚本字段表达式。

## 10. 常见诊断

| 现象 | 优先检查 |
| --- | --- |
| 等待生成 / 找不到模型 | 目标跟随没有编辑态实例时是正常等待；检查生成器是否输出同一类型，来源、生成器范围、编号类型和字符串编号是否一致，以及模型是否加载完成。 |
| 命中多个实例 | 补齐来源和编号，或在运行预览 / Viewer 目标跟随面板明确选择；不会任意取第一项。 |
| 测试继承绑定失败 | 检查设备三元组是否完整及所选继承身份；货物容器号不能当作设备号。目标未生成不妨碍显式设备身份取数，承载者未知时用独立数据配置。 |
| MQTT 一直等待 | 检查已有连接是否收到对应设备快照。测试按钮本身不建立 MQTT 连接。 |
| HTTP 查询失败或设备不存在 | 检查托管数据源 ID、`namespace`、实际设备类型/编号、中台配置及权限；`sourceId` 不能代替 `namespace`。 |
| 取数成功但效果没有变化 | 检查字段路径、目标属性是否可绑定、倍率/单位、枚举是否覆盖当前值、是否点击“应用数据配置”，以及触发条件是否成立。 |
| 区域指标错位或缺失 | 对齐数据记录 ID 与已绘制区域 ID，不按数组顺序或区域显示名称关联。 |
| 镜头暂停 | 检查人工接管、其他跟随实例、巡检/漫游控制权；需要时在运行诊断中恢复跟随。 |
| 生长完成仍只显示部分 | 检查外部进度是否达到 1、显示上限是否为 100%，以及是否绑定到了预期部件。 |
| 参数编辑无法应用 | 查看 JSON/类型/范围错误；复杂行和数据绑定都需要显式应用草稿。 |
