# 数字孪生相机运动幅度统一标准

## 1. 适用范围

本标准适用于：

- 编辑器 `Scene View`；
- 编辑器运行预览；
- 发布后的独立 Web Viewer；
- 后续新增的数字孪生 3D 视口。

所有入口必须复用 `src/runtime/babylon/cameraControlStandard.ts` 和 `createBabylonViewport()`，不得在页面或业务模块中各自设置旋转角度、平移比例、缩放步长或近距保护。

## 2. 原有键位保持不变

| 操作 | 原有输入 | 说明 |
| --- | --- | --- |
| 选择模型 | 左键短点击 | 没有驱动相机时执行模型拾取。 |
| 旋转视角 | 右键拖拽 | 围绕当前 `target` 进行轨道旋转。 |
| 移动视角 | 中键拖拽 | 平移相机观察中心。 |
| 备用移动 | `Ctrl+左键`拖拽 | 保留已有辅助平移习惯。 |
| 缩放视角 | 鼠标滚轮 | 按当前相机半径百分比缩放。 |

本次统一只调整运动幅度，不改变上述按键，不把左键改成旋转，也不取消右键或 `Ctrl+左键`。

## 3. V2 幅度标准

场景灵敏度默认值为 `10` 时：

### 3.1 旋转

- 水平和垂直旋转均为 `0.3°/px`，即 `π/600 rad/px`；
- 不考虑惯性尾迹时，鼠标拖动约 `300 px` 对应旋转 `90°`；
- `rotate` 灵敏度按线性倍率调整，例如 `20` 为 `0.6°/px`，`5` 为 `0.15°/px`。

旋转使用明确的弧度/像素输入，不再依赖不同入口各自换算 `angularSensibilityX/Y`。

### 3.2 平移

- 默认采用约 `1:1` 屏幕空间幅度：鼠标移动 `1 px`，观察目标在画面中移动约 `1 px`；
- 世界坐标位移根据相机 `radius`、垂直 FOV 和实际画布高度动态计算；
- 远景自动增大世界位移，近景自动减小，不再使用与场景尺度无关的固定米数/像素；
- `pan` 灵敏度作为线性倍率，例如 `20` 为约 `2 px/px`，`5` 为约 `0.5 px/px`。

透视和正交模式使用同一取景高度换算规则；画布尺寸或相机距离变化后会自动刷新平移比例。

### 3.3 缩放

- 默认每档滚轮改变当前 `radius` 的 `5%`；
- `zoom` 灵敏度按线性倍率调整，例如 `20` 为 `10%`，`5` 为 `2.5%`；
- `zoomToMouseLocation = false`，继续围绕当前观察中心缩放。

### 3.4 近距保护

- 最小相机半径：`0.2 m`；
- 近裁剪面下限：`0.02 m`；
- 透视投影按当前相机半径动态取 `max(0.02 m, radius × 0.001)`；
- 正交投影继续使用 `0.02 m`，其线性深度不需要按半径放大 near plane。

动态近裁剪既保留贴近模型时的 2 cm 观察能力，也会在缩远到大尺度场景时提高深度缓冲精度，避免相邻外壳表面出现条纹、闪烁或缺面；该规则不随灵敏度改变。

### 3.5 聚焦约束

模型聚焦操作（编辑器场景聚焦和发布 Viewer 的设备聚焦）统一通过 `createBabylonViewport().focusOnBounds()` 或 `focusArcRotateCameraOnBounds()` 完成，结果相机位姿必须满足：

- 聚焦中心与位置：始终以模型最新世界包围盒中心作为 Target，保留当前水平方向并从模型斜上方 `45°` 看向中心（`beta=π/4`）；
- 聚焦距离：常规模型聚焦半径优先为 `2 m`，按包围盒适配在 `2–3 m` 内；包括改大后的链条机在内，模型中心到相机的距离硬性限制为最大 `3 m`，不再为完整显示大模型而突破上限。环境全景等非模型目标可显式取消该上限并保留当前观察方向。近距保护（最小半径 `0.2 m`）继续生效。

常量统一放在 `DIGITAL_TWIN_CAMERA_CONTROL_STANDARD.focus`（`minCameraHeightMeters`、`preferredRadiusMeters`、`maxRadiusMeters`、`defaultBetaRadians`），编辑态、运行预览和发布 Viewer 使用同一实现。

发布 Viewer 接收 `focusAsset` 命令时不播放相机过渡动画，命令触发后立即进入上述模型聚焦位姿，避免中间帧短暂保留旧模型的距离或观察方向。

## 4. 模型表面的视角操作

“模型视角穿透”指相机输入不被模型拾取层阻断，不是模型透明或网格物理碰撞：

- 在模型表面按右键旋转、中键平移或使用滚轮时，相机操作正常执行；
- `Ctrl+左键`平移只要实际驱动相机，就不执行模型选择；
- 普通左键短点击仍选择模型；
- 左键会话只要 Babylon 已累计相机输入，或 `alpha`、`beta`、`radius`、`target` 已变化，就优先按相机操作处理；
- 没有驱动相机且按下/释放距离不超过 `4 px` 时，才执行模型拾取。

## 5. 实现约束

- `cameraControlStandard.ts` 是键位恢复、角度/像素、屏幕空间平移、缩放步长和近距保护的统一实现；
- 创建视口及视角动画恢复控制时统一调用 `attachDigitalTwinCameraControl()`；该入口会在 Babylon 完成 `attachControl()` 兼容参数写入后恢复中键平移、右键旋转和当前灵敏度，禁止业务代码直接重绑相机；
- 平移比例在渲染前依据最新 `radius`、FOV 和画布高度同步；透视近裁剪面依据最新 `radius` 同步；
- 标准应用必须幂等，重复执行不得产生重复鼠标映射；
- Gizmo 拖拽不得重新 `attachControl()` 并破坏中键平移；
- 调整标准时应同步版本、文档和契约测试，不得只修改某个页面。

## 6. 回归验收

1. 左键短点击模型仍可选择；
2. 左键空白点击仍可清空选择；
3. 右键在空白和模型表面都可旋转；
4. 中键在空白和模型表面都可平移；
5. `Ctrl+左键`仍可平移且不会误选模型；
6. 滚轮在空白和模型表面都可缩放；
7. 默认旋转输入为 `0.3°/px`；
8. 相同画布位移在远近视角下保持近似一致的屏幕平移幅度；
9. 默认滚轮步长为当前距离的 `5%`；
10. 编辑器、运行预览和发布 Viewer 的结果一致；
11. Gizmo 拖拽结束后中键平移仍然有效；
12. 透视相机缩远时近裁剪面随半径提高，正交视图与贴近模型的近景仍保持 `0.02 m` 下限；
13. 模型聚焦以最新世界包围盒中心为 Target，保留当前水平方向并使用斜上方 `45°` 视角；
14. 模型距离优先为 `2 m`、按包围盒适配在 `2–3 m` 内，任何模型的中心到相机距离均不得超过 `3 m`；环境全景可显式取消该模型上限并保留当前观察方向。

自动契约测试位于 `tests/digitalTwin/cameraInteractionStandard.test.ts`、`tests/digitalTwin/assetFocusCameraTransition.test.ts` 与 `tests/telemetry/environmentRuntime.test.ts`。
