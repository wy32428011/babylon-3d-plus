# 工厂 FPS 优化（2026-10-27）

用户授权按已交付方案开始优化，设备行为与业务逻辑保持不变。对象为当前“中鼎智能-工厂”383 实体场景；历史约 11.5 FPS / GPU P50 57.46 ms 仅作定位，不冒充本轮基线。

## 边界与交付

- 保留 MQTT、脚本更新频率、设备身份、运动部件、拾取、参数编辑、显隐、撤销和保存语义。
- 原 Platforms 场景、模型及外置脚本只读；如需画质配置对照或资产修订，使用明确独立副本，不覆盖原件。
- 优先使用现有动静合批、光照分类及阴影缓存。未知回调、材质/几何变化及不受支持的渲染路径继续保守回退；不按文件名直接放行。
- 阴影降档与运动降分辨率已有显式选项，本轮不偷偷改变全局画质默认值。LOD、全工厂 GI 烘焙、发布和提交不在当前首批范围内。
- 目标是交付可用且有证据的首批优化，不预先承诺 30 FPS 或未测量的收益。

## 先前的渲染工作量检查

实际 Web Editor / RTX 2070 SUPER / ANGLE D3D11 / WebGL 2，同相机、1000×607 渲染表面。三组均为 3913 个 Mesh、2323 个 active mesh、主视图估算 1,682,469 个三角形，加载错误为空。

| 配置 | 缓存稳定后的 Draw Calls | 静态 / 动态投影物 | 阴影贴图及缓存估算 |
| --- | ---: | ---: | ---: |
| 原配置 | 6009 | 798 / 2812 | 192 MiB |
| 只修正固定部件分类，保留高质量阴影 | 5700 | 1527 / 2083 | 192 MiB |
| 固定部件分类 + 均衡阴影（交付配置） | 3200 | 1527 / 2083 | 24 MiB |

绘制数量下降约 46.7%，阴影贴图及缓存估算下降 87.5%。这是工作量/资源预算变化，不能换算成相同比例的 FPS 收益。原配置的首次重建 7632 DC 样本仍保留在原始事件中，没有使用峰值夸大收益。

预览页后台 `requestAnimationFrame` 一度完全不推进，随后使用原 Engine 已注册渲染回调显式推进帧，完成真实 WebGL 绘制、缓存和画面检查。因此本轮不将墙钟帧率、人工推进帧或原始 CPU/GPU 计时用于正式性能验收，未证明前台达到 30 FPS。没有修改渲染循环产品实现。

原关联大屏存在 `ERR_CONNECTION_TIMED_OUT`；未替换链接、隐藏错误或开展外部服务修复。未连接真实 MQTT，因此不声称完成生产设备回放验收。
