# GLB 标准预览与默认环境照明

## 目标与授权

- 用户确认实现“GLB 标准预览”预设及默认环境照明，普通模型与环境模型共用，尽量对齐 Babylon Sandbox。
- 保留已有场景配置；用 `展会_保画质精简.glb` 验证保存重开及本地 SOURCE/DIST 发布后的显示效果。
- 基于当前有大量未提交改动的工作区增量实现，不提交、不推送、不上线；原始 GLB 不改写。基线存于 `output/glb-standard-preview/baseline.json`。

## 设计约束与顺序

1. 配置增量：旧文档缺少新环境选择字段时沿用场景天空盒；只有新建场景或显式应用标准预览才选内置 Sandbox 环境；新建场景仅默认增加环境，保留可编辑主光/补光，完整纯 IBL 基线由显式预设切换。
2. 离线环境：内置与 Sandbox 默认相同的预过滤环境及旋转；照明不依赖天空背景可见性，Editor/Viewer 通过构建资源加载，不运行时访问 CDN。
3. 预设为一次草稿操作，同时暂存灯光和显示参数；应用、撤销和保存沿用现有事务。保留模型材质、规则及已有资源，真实照明变化使已有 GI 失效。
4. 两入口共用运行时；补齐异步就绪、失败、重试和切换释放。新环境输入进入烘焙签名，避免错误复用旧结果。
5. 聚焦回归、类型/构建、独立审查；真实 Electron 使用该 GLB 保存重开，正式本地导出 SOURCE/DIST 后检查离线 Viewer。
