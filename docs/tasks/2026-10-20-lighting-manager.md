# 集中式光照与烘焙管理器

## 目标与授权范围

- 用户确认按方案及三张 UI 图实施；管理范围为当前场景。
- 将本次光照/烘焙配置收拢到单一管理器，模型 Inspector 只保留来源摘要与定位入口。

## 实施顺序与分工

1. 共享纯规则合同、规范化和优先级解析；补默认继承、顺序、例外和节点失配回归。
2. 运行时按实际模型来源应用规则；联通组合、生成、阵列/实例和环境；接入资源迁移与签名。
3. 集中管理器、场景/对象摘要入口；本地草稿、影响预览、单次撤销与锁定保护。
4. 主任务整合 SceneDocument/Serializer/Store、真实预览与宿主；同步保存发布链路。
5. 聚焦测试、类型/构建、独立审查，以及实际 Electron/Viewer 点击和运动验证。
