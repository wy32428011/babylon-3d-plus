# 报警管理器参考图外观

更新日期：2026-09-24。

报警管理器的“参考报警样式”提供下列十二项预设。选择后仍可在“报警外观属性”内调整颜色、强度以及对应效果的视觉和专用参数。预设保存为完整 `appearanceEffect` 配置，保存场景、重新打开和发布 Viewer 时使用同一份配置。

| 参考图 | 编辑器样式 | 效果类型 | 实现表现 |
| --- | --- | --- | --- |
| 01 | 设备变红 / 变橙 | `model-color` | 对报警设备着色，可将主颜色改为红色、橙色等 |
| 02 | 闪烁高亮 | `model-flash` | 按闪烁参数改变报警设备高亮 |
| 03 | 呼吸光晕 | `breathing-ring` | 设备底部周围显示亮度变化的光环 |
| 04 | 描边轮廓高亮 | `model-outline` | 对报警设备显示发光轮廓 |
| 05 | 顶部报警灯 | `warning-beacon` | 设备顶部显示旋转警示灯 |
| 06 | 告警图标悬浮 | `alarm-icon` | 悬浮三角告警标识 |
| 07 | 报警光柱 | `light-pillar` | 红色半透明光柱，可调整高度和范围 |
| 08 | 波纹扩散 | `ripple-ring` | 设备周围周期性扩散的环形波纹 |
| 09 | 地面警戒圈 | `alarm-zone` | 设备周围显示警戒范围 |
| 10 | 弹窗 / 标签告警 | `alarm-label` | 设备旁显示告警信息卡 |
| 11 | 烟雾 / 火花 / 粒子 | `smoke-plume` | 预设显示烟雾，也可从特效库替换为火花或其它粒子效果 |
| 12 | 路径指引到故障点 | `alarm-route` | 显示朝向故障设备的指引路径 |

第 03–12 项默认保留设备自身颜色，通过局部外观表达报警；“覆盖设备颜色”可按场景需求单独设置。旧场景未保存该开关时继续沿用原有颜色覆盖行为。

## 使用步骤

1. 在 POI 库加入报警管理器，设置目标 Size，将模型库设备拖入目标槽位；需要限定单台设备时选择 `ENTITY` 和具体场景设备。
2. 将监听属性设为 `CUSTOM PROPERTY`，例如火警属性填 `normal`、触发值填 `true`。
3. 从“参考报警样式”选择一种外观，在“报警外观属性”内调整所需属性，然后保存场景。
4. 进入运行预览。目标设备收到对应点位且值匹配时显示所选外观，未命中的其它设备保持原状。

外观目标和激活条件由报警管理器决定，无需再次为外观绑定 MQTT 或目标。外观参数的修改不会给管理器额外添加独立 POI 特效实体。

## 点位保持规则

- 首次收到火警点位后，使用该点位最后一次收到的值判断。
- 没有新值、超过设备遥测超时时间、重复收到相同值，以及仅更新其它点位，都不会解除自定义属性报警。
- 收到不匹配的新值时解除报警，恢复原材质并移除附着外观。
- 停止预览或显式清空该数据源后清除运行时保持值；值不写入场景文件。
- `RUNNING STATE` 继续使用原有设备状态和超时规则。

## 本地验证

运行配置回归：

```powershell
node --test tests/editor/alarmReference.test.mjs
```

运行真实浏览器回归：

```powershell
node scripts/smoke-alarm-reference.mjs
```

浏览器脚本使用独立 Vite 缓存和动态端口，逐项向实际 `AlarmManagerRuntime` 提交经 MQTT `p/v` 解析的消息，检查像素、动画帧、正常设备隔离、设备移动跟随、点位保持和解除后的资源释放。另通过真实编辑器控件完成模型目标拖放、十二项样式选择、属性修改、保存重开及预览。

已有一次完整通过记录后，修改部分效果可定向复核，例如：

```powershell
node scripts/smoke-alarm-reference.mjs --kinds=light-pillar,ripple-ring,alarm-zone --skip-editor
```

定向结果写入 `result-focused.json`，保留完整回归的 `result.json`；总览组合当前逐项截图，避免重复执行未受影响的编辑器路径。

结果与逐项画布截图输出到 `output/playwright/alarm-reference/`，总览为 `reference-gallery.png`，断言结果为 `result.json`。这些是本地浏览器与本地消息验证，不代表已经连接现场 Broker、更新线上场景或验收已安装的 Viewer。
