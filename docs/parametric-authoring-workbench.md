# 参数化模型工作台

工作台已接入编辑器首页，入口为 **参数化工作台**。它使用独立的 Babylon 场景、工程状态和撤销历史，不修改原编辑器场景，也不覆盖导入的 GLB、元数据和脚本。

## 启动

### 当前模型工作目录

在 `E:\公司文件\数字孪生\模型文件` 双击 `打开参数化工作台.cmd`。它复用已运行的工作台；否则启动本地服务并打开浏览器。地址：

[打开本地工作台](http://127.0.0.1:5178/?tool=parametric)

本地启动脚本复用 `C:\temp\babylon-3d-plus` 的源码和已安装依赖，要求宿主支持的 Node.js 版本。它不是独立安装包；本次未覆盖已安装或已发布的编辑器。

开发服务只监听 `127.0.0.1`，只读展示当前导出包中的 69 个模型。端口被其他程序占用时拒绝启动，不结束不明进程。自己通过命令窗口启动的服务，可在该窗口按 `Ctrl+C` 停止。

### 编辑器源码

正常启动此源码版本的编辑器后，在首页点击 **参数化工作台**。开发浏览器也可通过 `?tool=parametric` 直接进入。普通宿主入口没有本地目录服务时，使用 **打开文件** 导入资产，不依赖 Electron 文件对话框。

开发服务可用 `AUTHORING_APP_ROOT`、`AUTHORING_MODEL_ROOT` 和 `AUTHORING_PORT` 指定源码、只读模型包与端口；双击启动器的复用检测使用默认端口 5178。

## 一次完整操作

1. **打开模型**：选择 GLB、原模型 ZIP 或 `.pa.zip` 工程。也可从当前本地模型库选择；多模型 ZIP 会显示候选列表。
2. **选择部件**：点击三维模型或左侧部件列表。`Ctrl` / `Shift` 支持多选；使用“聚焦所选”“隔离显示”，或保存并命名部件组。
3. **定义参数**：在“参数”中新建数值、开关、颜色或文本，填写英文标识、显示名称、默认值及约束。规则表达式引用参数标识，而非中文显示名称。
4. **添加规则**：选中目标后进入“规则”，选择轴向尺寸、固定两端伸缩、偏移、旋转、阵列、显隐或整件颜色。指定方向、固定端与表达式。
5. **编辑表面**：在“外观”中新建独立颜色区域，或导入图片后在表面放置贴花。
6. **保存工程**：生成 `.pa.zip`，同时保存本机恢复副本。以后通过“打开文件”重新打开，或从空白工作台恢复本机副本。
7. **导出模型包**：生成 `.model.zip`，包含 GLB、兼容的参数脚本、元数据、图像、编辑配方及原资产备份。先处理面板中的错误再导出。

`Ctrl+S` 保存工程；输入框外的 `Ctrl+Z` / `Ctrl+Shift+Z` 或 `Ctrl+Y` 撤销、重做。视口聚焦时按 `F` 聚焦所选；绘制多边形后按 `Enter` 完成，按 `Esc` 取消。

本机恢复副本按浏览器与访问地址隔离；`localhost`、`127.0.0.1` 和桌面编辑器之间不共享同一份浏览器存储。需要长期保留或跨环境移动时，使用 `.pa.zip` 文件，不仅依赖恢复副本。

实际界面：[模型工作台](assets/parametric-authoring-workbench.jpg) · [局部改色与贴图定位](assets/parametric-authoring-surface.jpg)。

## 参数与几何

- 数值与表达式的尺寸运算使用**米**，角度使用**度**。参数显示单位填写 `mm` 或 `cm` 时只转换界面输入和显示，内部仍保存米；导出给宿主的尺寸单位为米。
- 支持常用算术、比较与条件表达式，以及 `min`、`max`、`floor`、`ceil`、`abs`、`clamp` 等白名单函数。它不是 JavaScript 编辑器，不支持属性访问、任意函数调用或 `eval`。
- “派生表达式”引用其他参数并显示计算结果；未知引用、循环依赖、除零和非有限值会报错。
- 轴向尺寸以原始状态为基线，反复修改不叠加误差。伸缩规则可声明两端刚性长度；固定区容纳不下时拒绝更新。
- 阵列支持三轴数量和步距，也支持沿指定轴按跨度及间隙铺满；数量包含源件。通用阵列的总实例预算为 1000，超限拒绝，不截断生成。
- 同一部件同一通道的冲突规则会被拒绝。几何规则按尺寸、旋转、平移、外观、阵列的明确顺序执行，不依赖偶然的界面顺序。
- 默认值与当前值分开保存。“设为默认值”才更新参数默认值；导出元数据分别保留默认值与当前配置。

## 贴图位置

**局部贴花**用于 Logo、标识与铭牌：

- 导入 PNG、JPEG 或 WebP，随后在模型表面点击，或按住左键拖动定位。
- 默认保持图像宽高比，尺寸按米设置；可解除比例锁定，修改角度、透明度及横纵偏移。
- 在图层中选择“在模型表面重新定位”，可更换锚点。
- 贴花限制在指定部件及投影范围内，默认不投到背面；通过区域宽高、深度和偏移编辑裁剪范围。
- 可将宽高、角度、透明度和位置偏移绑定到参数。颜色和显隐绑定使用对应参数标识。
- 默认锚定表面并保持实际大小；也可选择随部件缩放。源三角形和重心锚点用于跟随变形，不只保存世界坐标。

**UV 表面纹理**使用模型已有 UV，可设置 UV 通道、偏移、角度和重复次数。缺少相应 UV 时明确报错；局部投影不等于自动 UV 展开，也不保证无失真包裹任意复杂曲面。保持平铺密度需要有效表面锚点。

## 局部颜色区域

同一 Mesh 内可以有多个独立颜色层：

- **整件改色**：对当前选中的部件建立颜色层。
- **所选面改色**：使用视口“选表面”，点击三角面，`Ctrl` / `Shift` 增减，然后创建颜色层。已有面区域可加入、减去或替换为当前面选择。
- **矩形区域**：在表面拖出范围，随后调整区域尺寸、位置与角度。
- **多边形区域**：在同一表面依次点击轮廓点，回车完成；可继续编辑归一化顶点坐标及区域范围。

提供“覆盖基础颜色”和“保留纹理细节调色”。默认不改变原法线、粗糙度或金属度；图层从上到下依次合成，靠后的层覆盖前面的层。新增贴花为白色乘色，不会自动染成区域默认蓝色。

局部面域按原三角形区间隔离，投影区域按表面位置裁剪；重叠 UV 不应使目标区域外跟着改色。删除或关闭图层恢复下层外观。当前工程最多启用 8 个外观层，达到预算会明确报错。

## 现有参数化脚本

已内置以下三个**原脚本摘要白名单**模板：

- 辊道输送线：保留伸缩、滚筒铺排、站台和部件显隐逻辑。
- 横梁式货架：保留层列阵列、结构尺寸以及逻辑货位输出。
- 多穿小车：保留整车尺寸、固定区域、载货板及原有业务字段。

匹配模板时，预览通过正式 `ExternalModelScriptRuntime` 执行原逻辑；新规则在其后应用。导出时组合原运行类和新增配方，不把原业务逻辑替换为粗糙整体缩放。

**其他历史脚本只保留文件，不自动执行，也不承诺无损反编译。** 可读取其参数声明，但需要自行建立可视化规则才能改变几何。其导出包的活动脚本只运行新配方，旧代码保存在 `originals/`，不会覆盖源文件。工具生成的配方通过 `.pa.zip` 继续编辑。

## 文件内容与安全边界

`.pa.zip` 是可继续编辑的工程：

- `authoring.json`：参数、部件、区域、规则、外观层与源资产版本。
- `assets.json` 与资产文件：GLB、图片、原元数据和脚本，并记录 SHA-256。

`.model.zip` 是宿主运行包：

- `manifest.json`。
- `models/0001-authored/model.json`。
- `files/model/` 中的 GLB 和贴图。
- `files/meta/meta.json` 与 `files/scripts/parametric-authoring.model.ts`。
- `authoring-recipe.json`、`originals/` 及 `integrity.json`。

图像同时作为包资源交付，并在生成脚本中内嵌运行所需数据，避免依赖工作台 Blob URL 或原电脑路径。ZIP 检查路径穿越、条目及展开体积；输入 ZIP 最大 256 MiB、展开总量 512 MiB，图片单文件最大 32 MiB。生成脚本及内嵌图像合计最大 12 MiB，超限提示缩小图片，不自动压缩或丢弃内容。

更换源 GLB、改变拓扑或丢失绑定时，需要重新核对部件与区域；不静默匹配另一个同名零件。未保存时返回首页、关闭浏览器或桌面窗口会提示保留工作。

## 当前明确限制

- 面向静态索引三角形的 GLSL PBRMaterial / StandardMaterial；不提供任意 ShaderMaterial、WebGPU、骨骼或 Morph 表面的通用编辑。
- 已有硬件实例或 ThinInstance 的独立表面编辑明确拒绝，需要先转独立 Mesh。通用工作台生成的阵列副本为独立几何；选择阵列副本按源部件组编辑，未提供单个硬件实例的独立贴图作者模式。
- 原有三个模板继续使用自己的实例预算；通用新规则另受 1000 实例预算约束。
- 分段伸缩保持原拓扑，不自动插入固定区边界切面；需要精确刚性边界的模型，应已有合适分段或使用既有专用模板。
- 没有自动 CAD 特征恢复、自动部件语义识别或 AI 生成纹理。
- 本次交付为源码功能与本地启动入口，没有生成 Windows 安装包，没有发布远程模型库，也没有改写工厂场景或现有资产。
