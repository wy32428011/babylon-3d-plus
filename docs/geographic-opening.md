# 参考地理开场包

更新时间：2026-09-29。

当前参考动画以 **reference-huishan-1.1.0.dtopening** 提供。未导入、未应用时没有这套开场参数，也不会自动创建或播放内置参考动画。包格式、版本、迁移及发布降级规则见 [开场动画包](opening-packages.md)。

## 使用方式

1. 在场景属性“开场动画”中导入参考包，并点击“应用到当前场景”。
2. 配置该包声明的品牌、公司、标题、画质、显示界面和科技呼吸；通过分镜编辑各段时长和 UV 飞线。
3. “抵达说明”留空时显示公司名称；填写自定义说明会覆盖这条默认说明。
4. 点击“预览开场动画”打开独立预览层。关闭预览只移除开场，不复位或接管三维相机。
5. 按需启用“进入场景时播放”，保存后重新发布。

| 24–30 秒 | 中国全景 | 6 秒 |

| 34–42 秒 | 国内业务 | 8 秒 |

这些阶段沿用参考画面的内容和顺序。修改一段时长只改变该段持续时间，其后阶段按新时间顺延。默认公司文案为“中鼎智能(无锡)科技股份有限公司”，可在面板修改。

## 点位与画面

世界和国内飞线使用底图归一化 UV：左上 (0,0)、右下 (1,1)，不是经纬度。默认全球40条、国内34条示意线路；空路线和零秒业务停留都保留。固定九段顺序来自原参考图，不随线路起点改变。

品牌和公司文案只控制叠加文字。部分公司名、地图注记已烘焙在图片像素内，完整更换需替换底图。素材来源见 [数据与素材说明](geographic-opening-data.md)。

科技呼吸默认开启、强度0.65、周期4秒；关闭或强度0保留基础线路运动。动效偏好支持完整、减少动态和跟随系统。

## 与三维业务的关系

三维模型、脚本、数据驱动、巡检和漫游独立运行。开场不保存或恢复业务相机，不设置“结束后停留/启动巡检”；结束时显露已经运行中的业务场景。旧内置配置的这类业务控制动作不再生效。

开场包不可用不会阻断有效三维发布，发布副本会省略开场并给出明确提示；本地配置保留。普通三维资源或基础 Viewer 错误仍严格阻止发布。

## 旧配置迁移

原内置配置保存重开时原样保留，显示待迁移提示。导入新版参考包后选择“迁移旧配置到此包”，再检查并保存。迁移保留视觉参数，支持撤销。未知经纬度地点不能自动当作 UV，无法匹配时保留原数据并报告，不静默丢点位。

## 验证入口

运行 node --experimental-strip-types scripts/build-opening-packages.mjs 生成可导入包。真实 SOURCE/DIST 与编辑器、Viewer 浏览器验收见 [开场包验证](opening-packages.md#验证范围)。
