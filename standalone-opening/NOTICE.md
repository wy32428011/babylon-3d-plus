# 来源说明

本插件复用当前项目的参考版开场实现。九张参考画面和一张地球纹理来自用户提供的 `zd_digital_twin_opening.html`，以原始 WebP 随源码保存，未重新生成或替换原图。

参考动画的球面展开、地图推进、动态飞线和界面由当前项目原生 WebGL / Canvas2D 适配代码实现。独立 SDK 封装其播放时钟、可见性、生命周期和宿主回调，不包含 React、Electron、Babylon 或在线地图服务的运行依赖。构建工具及其依赖不随浏览器运行。

源码和参考图片沿用原有授权范围。本包只记录来源，不新增或扩大授权，也不将参考图片标记为 MIT、CC 或公共领域素材。

地图、点位、飞线为视觉示意，不表示真实航班、实时物流或实际业务覆盖；末段淡出由宿主接入业务内容，不代表图片和真实业务模型已做 GIS 配准。图片中已烘焙的品牌与地图文字属于像素，修改配置只能改变叠加文字。

详细视觉来源和原渲染器说明见 `source/ASSET-SOURCE.md`。
